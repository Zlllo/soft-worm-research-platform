# 原平台算法、身体模型与可调参数说明

> 本文保留此前阶段的快照。2026-10-08后续连续导航优化与实测结果见 [最新验证报告](../docs/reports/ccb-continuous-navigation-2026-10-08.md)，CCB现使用相对转向、14维AC观测与连续奖励。

核查日期：2026年10月6日。对应当前项目的 `程序/app.py`、`程序/core/worm_body.py`、`程序/core/actor_critic.py` 和 `程序/core/neural_networks.py`。本说明记录代码实际行为，不表示已经验证长期训练效果。

## 1. 身体、动作与算法是三个不同层次

- 身体模型决定动作如何变成身体位形和运动：Worm2D、CCB、ADB。
- 动作空间决定策略能够输出什么：4/8方向、连续朝向与步长、连续波参数。
- 学习算法决定怎样根据经验改进动作：Q-learning、DQN、Dueling DQN、DDPG。

CCB是ContinuousCenterlineBody（连续中心线身体）；ADB是ActiveDeformationBody（主动形变身体）；DDPG是Deep Deterministic Policy Gradient（深度确定性策略梯度），属于Actor-Critic算法。

## 2. 界面上为什么只有4/8方向

当前 `app.py` 第1025行附近按身体模型设置选项：

| 模型 | 标准训练中的动作选项 | 可用算法 |
| --- | --- | --- |
| 多节段链条Worm2D | 4方向、8方向 | Q-learning、DQN、Dueling DQN |
| 连续中心线CCB | 4方向、8方向、连续方向 | 离散动作使用Q-learning/DQN/Dueling；连续使用Actor-Critic |
| 主动形变ADB | 固定连续波参数，不显示方向选择器 | Actor-Critic |

先选择标准训练，再展开左侧“身体形态设计”，在“身体模型”中选择“连续中心线”。这时动作空间应增加“连续方向（Actor-Critic）”。选择ADB时直接显示连续波参数说明。PyTorch不可用时，连续控制会报错。

如果选择CCB后仍只有两项，应核对实际运行文件：停止原终端服务，在项目根目录用 `python3 -m streamlit run 程序/app.py` 重启。当前源码条件已核查，但没有读取用户当前浏览器页面，不能认定正在运行的是哪一个版本。

## 3. 各种学习算法

### Q-learning

维护状态—动作价值表Q。当前网格实现主要按位置索引，为每个格点记录各方向的长期收益估计；探索时随机选动作，利用时选择最大Q值的动作。更新为：

\[
Q(s,a)\leftarrow Q(s,a)+\alpha\left[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\right].\tag{1}
\]

这里s是状态，a是动作，r是当步奖励，alpha是表值更新权重，gamma是未来收益折扣。表格依赖状态定义；按绝对位置查表不能直接理解成跨地图泛化，也可能遗漏朝向等影响后续行为的变量。

### DQN

用神经网络替代Q表，输入环境和身体状态，输出每个离散动作的Q值。经验回放把历史转移保存后随机抽样，目标网络提供更新目标。动作仍是离散的，网络输出实数Q值不代表动作是连续方向。

当前共享批训练函数采用Double DQN机制：在线网络选下一动作，目标网络估计该动作的价值。Double DQN不是当前界面的独立选项，也不同于Dueling结构。

### Dueling DQN

共享特征后分成状态价值V和动作优势A两支。前者估计“当前状态整体有多好”，后者估计“某动作比其他动作好多少”，合成为：

\[
Q(s,a)=V(s)+A(s,a)-\frac1{|\mathcal A|}\sum_{a'}A(s,a').\tag{2}
\]

它仍输出4或8个离散动作的价值。是否优于普通DQN需要本项目的对照实验；结构更复杂不自动意味着训练效果更好。

### Actor-Critic / DDPG

Actor输出连续动作；Critic根据状态和动作估计长期收益。Critic用经验数据拟合目标，Actor沿Critic评价改进动作；代码还使用目标网络软更新与OU探索噪声。

CCB的动作是(朝向角、步长参数)，默认执行边界分别为[-pi, pi]和[0.05, 5.0]。ADB动作是(波幅、频率、弯曲偏置)，边界分别为[0.05,2.0]、[0.02,0.8]、[-0.08,0.08]。这些是当前平台计算尺度，不是已标定生物量。

已有接入测试不证明收敛。ADB引擎测试只有一轮两步，小于默认64条经验的学习门槛；实际保存过程也由测试替代。正式训练与独立评估仍需完善动作边界、执行/回放一致性、停止学习的评估模式和checkpoint保存。

### 标准、迁移、课程学习

这是训练组织方式：标准训练在选定环境训练；迁移在源环境学习后到目标环境测试；课程按环境阶段推进。它们不是与DQN并列的新网络算法。当前非Worm2D模型只允许标准训练，迁移/课程尚未完整适配。

## 4. 身体与几何参数

原平台以格点/像素和程序时间步为主，不应直接解释成毫米、秒和SI材料参数。

| 界面参数 | 解释与当前行为 |
| --- | --- |
| 节段数量（Worm2D） | 身体表示的节点数；改变初始化、跟随链和记录数量。 |
| 节段长度（Worm2D） | 界面名称与实现不一致：代码把它作为总名义体长，目标节点间距为该值/(节点数-1)。 |
| 采样点数（CCB/ADB） | 用多少点表示或计算身体；增加点数改变空间分辨率与计算量，不代表生物长出了更多节段。旧ADB是身体轴向坐标采样，不是严格材料弧长采样。 |
| 身体总弧长（CCB） | 目标总长度，等距间隔用于几何修正；受迭代修正和边界裁剪影响，并非严格不可伸长方程。 |
| 身体总弧长（旧ADB） | 实际用于定义轴向坐标范围；叠加横向波后，真实曲线弧长可以改变。 |
| 头部半径、身体宽度 | 保存为几何描述；当前运动核心没有据此求解接触、碰撞半径或流体阻力。不能解释为已接入完整三维身体力学。 |
| 前进速度（Worm2D） | 已保存参数，但主move路径直接使用单位格点方向向量，不乘这个速度。 |
| 后退速度、转向速度（Worm2D） | 已保存，当前主离散移动路径没有按这些值区分前进、后退、转向。 |
| 前进速度（CCB） | 离散方向动作的默认期望速度幅度；连续DDPG路径由Actor输出step覆盖它。默认dt=1时表现为每步运动幅度。 |
| 最大转向角 | Worm2D和CCB保存该参数，当前主运动没有按它裁剪相邻动作的朝向变化；不能当作已生效的转向速率限制。 |
| 曲率限制角（CCB） | 实际是相邻折线段的弯折角阈值，超过时做平滑；不是严格微分曲率的单位。 |
| 长度刚度（CCB） | 每次长度修正向目标间距移动的权重，越大单次修正越强；不是杨氏模量。 |
| 曲率刚度（CCB） | 超过角阈值时向邻点平均位置平滑的权重，越大修正越强；不是具有SI单位的弯曲刚度。 |
| 运动阻尼（CCB） | 新速度=旧速度*damping+期望速度*(1-damping)。值越大越保留旧速度，响应越慢；不是已标定的黏性阻力系数。 |

## 5. ADB波形与RFT参数

| 界面参数 | 解释与当前行为 |
| --- | --- |
| 波幅（初始值） | 初始横向摆动幅度；Actor执行后按动作更新，滑块值不是训练期间固定波幅。 |
| 波频率（初始值） | 初始波振动频率；Actor执行后更新。原程序dt未标定，不宜直接称实际生物Hz。 |
| 波传播速度 | 相位推进倍率，当前相位增长为2*pi*f*dt*wave_speed。它不是身体前进速度；局部形变速度表达式未同步乘该倍率，取非1值时存在一致性问题。 |
| 波长 | 横向正弦波的空间周期，影响身体上有多少个摆动周期；固定参数，不由当前Actor输出。 |
| 弯曲偏置 | Actor第三维，改变左右弯曲趋势，使力与力矩平衡产生转动；界面初始化设0，未提供独立初始偏置滑块。 |
| 子步积分步数 | 一个决策步拆成多少物理步；增加可减小积分误差并增加动画帧，但不增加决策频率。 |
| 阻力系数（能耗尺度） | 整体缩放切向/法向阻力。在自由游动平衡求解中共同倍乘可约掉，固定形变下速度不变、功率同比缩放；若奖励或能量终止改变，训练轨迹可间接受影响。 |
| 法向/切向阻力比 | 原平台固定1.4，不是可调参数；该数值不能当作已验证适用于所有介质的生物常数。 |
| 冻结转向的决策步数 | 前N次动作把弯曲偏置强制为0，后续恢复；属于ADB内部动作安排，和侧栏“课程学习”不是同一功能。回放目前保存Actor原动作，强制修改后的执行动作可能与回放不一致。 |
| 头尾波幅包络 | 为行波乘空间包络，使轴向端部行波幅度减小；改变几何和推进，不表示已经验证所有线虫都有该固定波形。 |

## 6. 通用训练与DQN参数

| 界面参数 | 解释 |
| --- | --- |
| 实验名称 | 输出目录标识，不改变学习机制。 |
| 宽度、高度 | 温度网格尺寸；改变状态数量、相对身体尺度和到达距离。 |
| 环境类型 | 单/双热源、环形、斑点、迷宫和动态场等任务条件。 |
| 4/8方向 | 允许的离散动作集合。Worm2D的8方向对角每步距离为轴向的sqrt(2)，不能直接当同速公平比较。 |
| 训练轮次 | 重复轨迹数；各轮身体重置，学习状态继续保留。 |
| 每轮步数 | 每条轨迹决策次数上限；增加时总奖励也可能随时间增加，比较要统一窗口。 |
| 初始探索率epsilon | Q/DQN路径中随机动作概率的初始值；不是学习率。 |
| 最小探索率 | 标准训练的探索率下限；身体内部还可能调整实际探索。 |
| 探索率衰减 | 标准引擎按轮线性减小epsilon，每轮减该值，直到下限；不是百分比衰减。 |
| 学习率alpha | 表格Q-learning的新信息更新权重；不是DQN或DDPG优化器步长。 |
| 折扣因子gamma | 未来奖励权重，越大越考虑较长时收益；DDPG也读取此参数。 |
| 隐藏层大小 | DQN网络宽度；DDPG实际使用独立的“AC隐藏层大小”。 |
| 神经网络学习率 | DQN参数优化步长。 |
| 权重衰减 | DQN优化器中的正则项，用于限制权重增长；不保证泛化。 |
| 使用state_v2（Worm2D） | 单帧从8维增为10维，加入剩余能量比例和平均弯折指标；四帧输入由32维增为40维。旧Worm2D能量不衰减，该维可能缺少变化信息。 |
| 详细分析 | 开启额外统计和结果输出，不是更高级的学习算法；部分统计基于原任务定义。 |

## 7. DDPG专用参数与奖励

| 界面参数 | 解释 |
| --- | --- |
| AC隐藏层大小 | Actor和Critic网络宽度，默认128。 |
| Actor学习率 | 策略网络优化步长，默认0.0001。 |
| Critic学习率 | 价值网络优化步长，默认0.001。 |
| AC批次大小 | 每次从经验回放抽取的样本数，也是开始更新所需最少经验数；默认64。 |
| 探索噪声强度 | 连续动作OU噪声的倍率；较大时探索更强。当前噪声尺度还会随调用衰减，并受动作裁剪影响。 |
| 不含能量（原版） | 以旧温度奖励为基础；CCB/ADB的AC路径仍另加原地与约束违例惩罚，因此不是完全只看温度。 |
| 含能量（单步化） | 在温度奖励上减去当步能量消耗/max_energy乘权重；不是减去从开局累计消耗。 |
| 能量权重w_e | 单步能量惩罚强度；Worm2D当前DeltaE=0，因此对它无效果。CCB能量为经验扣减，旧ADB是未标定尺度的阻力功，不能直接跨模型比较真实焦耳。 |

Actor-Critic直接使用连续探索噪声，侧栏离散epsilon及Q表学习率不决定其探索和网络更新。

## 8. 噪声滑块的含义与生效范围

| 参数 | 预期含义 | 当前主路径 |
| --- | --- | --- |
| 位置噪声 | 运动随机扰动 | CCB把高斯扰动加到期望速度；Worm2D主move未使用，旧ADB覆写RFT步也未使用。 |
| 角度噪声 | 朝向随机扰动 | 当前主运动路径未实际接入；Worm2D仅保存该属性。 |
| 温度感知噪声 | 温度读数随机误差 | 当前原平台状态直接读取温度场，未将该滑块作为传感误差注入；与新点模型的真正含噪传感不同。 |
| 动作执行噪声 | 执行动作时的误差 | 此滑块未接入上述主路径；不要和DDPG探索噪声混淆。 |
| 噪声时间相关性 | 相邻扰动的相关程度 | 当前原平台主路径未使用此相关系数；DDPG OU噪声有自己的内部参数。 |

原界面的“布朗噪声”标签不能据此解释成已满足热力学涨落耗散关系的布朗运动。做噪声研究前，应验证扰动真正进入观测或运动，并定义随机源、单位与时间尺度。
