# 汇报来源与交付检查

受众：物理学本科科研项目指导老师。主要交付：离线 HTML 汇报页；Markdown 是可编辑正文与口述稿来源，静态 PNG/SVG 是后续汇报使用的科研图。

报告结构覆盖技术总结、研究范围、模型/实验设计、实测结果、方法与指标、限制/稳健性、下一步与待讨论问题。由于结果需要先定义时窗、删失和对照，模型与指标安排在主要实测结果之前。

## 数据来源

- 核心代码基线：`fd7add1`；本轮没有修改核心感知与动力学。
- 设计：`configs/phase1_progress_scan.json`，运行前固定；不是外部预注册。
- 完整配对记录：`results/phase1-progress-2026-10-04/*/paired-records.json` 与 CSV，完整目录为本地忽略产物。
- 归档的汇总、配置设计、图、数值门限、运行清单：`docs/reports/assets/phase1-progress-2026-10-04/`。
- 汇报生成：`analysis/build_progress_report.py`；模型统计：`analysis/phase1_progress_scan.py`。
- 报告工具要求 SQL 来源，所以生成器导入实际原始指标，执行归档的 SQLite 聚合和生存查询，并将结果置入原生报告数据集。Wilson/Bootstrap 区间由已验证的 Python 分析计算，SQLite 只将它们与指标聚合关联；没有声称 SQL 生成这些区间。

## 图表与表格设计

| 结果问题 | 报告形式 | 信息粒度与解释 |
|---|---|---|
| 冷热参考参数是否改善 | 两张精确表：组均值/到达区间与配对差区间 | 每侧128对；逐对先算差；不以Wilson重叠代替配对分析 |
| 首次进入何时发生 | 原生阶梯线图；静态PNG/SVG双面板作为证据归档 | 事件时间重复前后点，保留阶梯；4条系列都有可见组名；静态版两色实虚线 |
| 噪声与记忆的影响 | 原生九类柱图；静态二维格图归档 | 9格各32对；保留噪声、慢记忆、样本数；数值差不与不同单位混为一轴 |

静态图已检查单位、图例、事件阶梯、色标零点和标签；没有碰撞或裁切。静态扫描格图坐标为数值物理量，报告与图注用中文解释英文缩写。没有给探索格点做最优性排序或多重比较显著性声明。

模型与统计独立验证：`docs/validation/phase1-progress-validation-2026-10-04.md`。完整回归67项通过；本轮实际科学数据在不增加传感信息的条件下使用0.1s物理步长，构建与独立步长检查均通过。
