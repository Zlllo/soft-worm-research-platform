# 第一阶段：记忆、漂移与无量纲尺度

日期：2026-10-04。本文从当前控制器推导可处理的极限；解析基准和控制周期/时窗实验见 [理论与敏感性结果](phase1-theory-sensitivity.md)。点模型不包含身体形变或机械功。

## 1. 先明确状态与近似

完整状态至少包含位置、朝向、快慢记忆和采样/控制时钟。位置单独通常不是 Markov 过程。以下连续时间推导针对局部线性温度误差、无噪声、无死区、无上下界截断、微弱增益的极限；有限控制周期的实现须另做数值比较。记忆初态已衰减，且轨迹尚未跨过舒适温度的绝对值尖点或碰到边界。

以 s=±1 表示朝向，v 为速率，局部误差斜率 b=de/dx，其中 e=|T−T*|。朝舒适温度方向有 sb<0。控制信号为 I=m_s−m_f，反向率为 λ=λ₀−gI。下标 s 在 m_s 中表示慢记忆，在朝向变量 s 中表示正负方向。

## 2. 持续单方向运动时的记忆差

如果误差沿一段运动近似为斜坡 e(t)=e₀+At，则连续记忆的长期解为 m_i=e−Aτ_i，因此

\[
I=-A(\tau_s-\tau_f)=-vsb(\tau_s-\tau_f).\tag{1}
\]

这解释了方向选择：误差下降时 I>0，反向率降低，正在改善的运动延续更久。它描述持续单方向片段，不能直接当随机翻向轨迹的平均漂移。

实际程序按传感周期 h_s 更新指数记忆，而不是连续读取。令 q_i=exp(−h_s/τ_i)，递推 m_{i,n}=q_i m_{i,n−1}+(1−q_i)e_n。在离散斜坡 e_n=e₀+Anh_s 的稳定响应下，滞后为 e_n−m_{i,n}=Ah_sq_i/(1−q_i)。所以

\[
I=-A H,\qquad H=\frac{h_s}{\exp(h_s/\tau_s)-1}-\frac{h_s}{\exp(h_s/\tau_f)-1}.\tag{2}
\]

H 的单位是秒，h_s→0 时趋于 τ_s−τ_f。参考参数 h_s=0.1 s、τ_f=0.5 s、τ_s=5 s 给出 H=4.498501 s。持续运动时 |A|=v|G|=0.02 K/s，故 |I|≈0.089970 K。扣除 0.01 K 死区后，增益 g=4 K⁻¹s⁻¹ 对反向率的修正约 0.319880 s⁻¹：改善方向的未截断反向率为负，实际被限制为 0.01 s⁻¹；恶化方向约为 0.419880 s⁻¹。这个计算说明参考参数会触及下限；真正触及比例必须从控制时刻统计，而不能由斜坡近似代替。

## 3. 随机翻向下的弱响应漂移

无响应连续模型每次翻向改变 s 的符号，常率 λ₀ 的朝向相关函数为

\[
\langle s(t)s(t-r)\rangle_0=\exp(-2\lambda_0 r).\tag{3}
\]

指数记忆核 K_i(u)=τ_i⁻¹exp(−u/τ_i) 的积分均为 1。两个核相减后，当前误差 e(t) 的共同部分消失；用 e(t−u)=e(t)−vb∫₀ᵘs(t−r)dr，可得

\[
\langle sI\rangle_0=-vb\int_0^\infty(K_s-K_f)(u)\int_0^u e^{-2\lambda_0r}\,dr\,du
=-vb\frac{\tau_s-\tau_f}{(1+2\lambda_0\tau_s)(1+2\lambda_0\tau_f)}.\tag{4}
\]

每次翻向令 s 变成 −s，所以 d⟨s⟩/dt=−2λ₀⟨s⟩+2g⟨sI⟩。在局部平稳、弱响应的一阶近似中，用无响应相关性计算右侧，得到恢复性漂移

\[
u=v\langle s\rangle=-\frac{g v^2 b(\tau_s-\tau_f)}{\lambda_0(1+2\lambda_0\tau_s)(1+2\lambda_0\tau_f)}+O(g^2).\tag{5}
\]

这条式子比直接套用持续单方向斜坡多出相关性修正：记忆窗口内的随机反向会抵消部分温度趋势。只有 λ₀τ_s≪1 时，修正分母才接近 1。它是局部均匀误差斜率的响应系数，不是跨越舒适温度与边界的全局位置方程。

同一无响应连续模型的速度相关积分给出长时扩散系数

\[
D_0=\int_0^\infty v^2 e^{-2\lambda_0r}\,dr=\frac{v^2}{2\lambda_0}.\tag{6}
\]

参考 D₀=2×10⁻⁷ m²/s；这是无界连续模型的长时系数，有限反射域的均方位移最后受域大小限制。连续弱响应公式在参考 g=4 下形式代入会给出 |u|≈0.327 mm/s，超过固定速率 0.2 mm/s，明确表明该参数已超出一阶展开范围。使用它解释方向趋势可以，使用它预测当前强响应速率不成立。

## 4. 把尺度变成可比较的量

参考舒适带半宽 ℓ_T=ΔT/|G|=2.5 mm，个体横跨这一半宽的时间 t_T=ℓ_T/v=12.5 s。以下比值各自回答一个不同问题。

| 无量纲量 | 参考值 | 物理含义 |
|---|---:|---|
| σ_T/ΔT | 0.20 | 测温误差相对舒适带容忍宽度 |
| τ_f/t_T，τ_s/t_T | 0.04，0.40 | 记忆相对舒适带运动时间的长度 |
| λ₀τ_f，λ₀τ_s | 0.05，0.50 | 记忆期间发生随机反向的程度 |
| gHv|G|/λ₀ | 3.60 | 单方向趋势响应相对基础反向率；参考值不小 |
| δ/(Hv|G|)，δ 为死区 | 0.111 | 死区相对单方向趋势信号 |
| λ₀h_c，λ_max h_c | 0.02，0.10 | 每次控制间隔的事件尺度，决定有限周期误差 |
| L_domain/ℓ_T | 12 | 域大小相对舒适带半宽；此处长度是域长，不是身体长度 |
| t_obs/t_T | 14.4 | 180 s 观察时窗覆盖的运动尺度 |

这些量帮助区分三种变化：加大噪声会削弱局部趋势信息；加长记忆同时加强斜坡信号并增加翻向前历史的残留；加长控制周期会改变动作更新频率和离散反向模型。它们不能只用一个“记忆越长越好”的结论概括。

## 5. 本轮弱响应系数的数值检验

为单独检验式 (5)，新增连续时间、固定误差斜率的局部替代模型：b=+100 K/m，v=0.2 mm/s，λ₀=0.1 s⁻¹，保留0.5/5 s指数记忆，关闭噪声、死区和夹限，也不设边界或绝对值尖点。该模型延伸局部线性误差，不作为原有限域任务的轨迹结果。记忆相对误差的滞后变量 z_i=m_i−e 满足 dz_i/dt=−z_i/τ_i−vbs；两次事件之间可精确推进。

模拟采用 Poisson thinning：提议事件常率为 λ̄=λ₀+gv|b|(τ_s+τ_f)，在事件时以 λ/λ̄ 接受反向。由 |z_i|≤v|b|τ_i 可知该包络有效；本轮小增益的反向率始终为正。没有使用物理步长近似事件时间。每个增益固定64条独立轨迹，先舍弃500 s初态，再测量30,000 s平均位移速度；各增益使用不同种子块，不作跨增益配对推断。

| 增益 g / K⁻¹s⁻¹ | 一阶漂移 / mm·s⁻¹ | 实测均值 / mm·s⁻¹ | 均值标准误 / mm·s⁻¹ |
|---|---:|---:|---:|
| 0 | 0 | +0.0000834 | 0.000521 |
| 0.025 | −0.002045 | −0.001634 | 0.000454 |
| 0.05 | −0.004091 | −0.004181 | 0.000428 |
| 0.10 | −0.008182 | −0.007760 | 0.000432 |

四组的理论值均位于实测均值约1个标准误以内。这为固定斜率、连续时间、弱响应极限下的漂移系数提供数值支持；未用这组局部替代实验验证参考强响应、含噪、带死区的有限域结果。标准误来自独立轨迹均值，而非把时间帧当独立样本。64条轨迹的正态近似95%区间、全部256条轨迹记录、固定设计和脚本哈希见 [原始结果](reports/assets/phase1-theory-2026-10-04/weak-response.json)；复现入口为 `python3 analysis/phase1_weak_response.py`。
