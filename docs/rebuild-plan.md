# 软体线虫趋温项目：现状评估与重建计划

日期：2026-09-22。状态：PR 已合并；第 0 阶段基础已经在 `codex/phase0-foundation` 分支实现，后续阶段仍按本计划推进。

## 1. 研究目标与范围

研究问题：一个只能通过局部含噪测温、短期记忆和自身运动获取信息的柔性个体，怎样找到并维持在给定的舒适温度区域？身体运动怎样影响感知效果，以及相应的机械耗散？

已确认：物理学本科小科研；重点是机制、推导与解释；一维和点模型只作为初步探索与初步结论；最终需要有形变和真实机械耗散的身体；优先研究感知不准确；从静态简单梯度逐步增加复杂性；不以完成全部扩展为汇报前提。

本计划的工作假设（尚非用户最终选择）：二维、均匀牛顿黏性介质、低 Reynolds 数、单个个体、外部给定且不受个体扰动的温度场，初期阻力系数不随温度变化。研究受线虫启发的机制，不先声称复现真实线虫的神经回路或培养皿爬行。若最终选表面爬行，需要替换介质和接触模型，但可保留前面的感知与统计框架。

舒适条件定义为 |T−T*|≤ΔT，T* 预先给定，ΔT 是容忍半宽。主要观测位置暂定头部；身体平均温度作为后续评价/比较选项，不在不知情的情况下混入控制输入。

## 3. 当前项目与新目标的差别

### 本地版

- 已有温度场、三类身体接口、Q/DQN 路径、训练模式、动画和身体指标，是有用的原型与历史对照。
- `core/worm_body.py` 约 2,005 行，同时承担运动、感知、奖励、决策和学习。`simulation_engine.py` 约 1,627 行，直接导入 Streamlit/Matplotlib，批实验与界面耦合。
- `Environment2D.get_state_vector()` 直接提供四个邻点温差以及到 `best_point` 的距离；`best_point` 默认取温度最大点。这不能作为“单点局部测温”的控制输入。
- `get_temperature()` 对坐标取整。连续运动可能在多次物理步中读到同一格温度，产生台阶；新的解析梯度场应直接连续求值，栅格场需要明确插值。
- 当前主动形变模型主要在头部移动后重建波形，速度还有 `forward_speed + propulsion_gain*abs(A*f)` 这样的规定关系。
- 部分温度场生成函数重设全局 NumPy 随机种子；新实验须拆分环境、传感器、控制与初态随机源。

## 5. 分阶段研究计划

### M0：固定研究约定和可复现基础

任务：保存两个版本的 SHA 与验证记录；统一符号、单位、观测权限、时间尺度、舒适区、边界与机械功定义。确认介质选择，给出一个有量纲基准并核算 Re=ρUL/μ 是否足够小。

新核心用 Python/NumPy 起步，所需数值求解再引入 SciPy；绘图作为可选依赖，PyTorch 仅留给后续对照。锁定一次验证过的环境，不因重建顺便升级所有依赖。

交付：模型约定文档、参数表、实验配置、命令行入口；保存配置/种子/版本/环境/结果。验收：同一配置可重现；传感采样周期、控制周期、物理步长互相独立；控制器接触不到目标坐标和真实梯度。

### M1：含噪局部感知下的最简趋温模型

先一维、后二维。有朝向的运动点，固定速度，局部温度输入，短期记忆，随机改变方向。温度场先用 T(x)=T*+Gx，舒适区是条带而非一个最高温点。

候选机制：分别平滑近期与较早的温度，判断温度误差是否在增大；恶化时提高改变方向的频率，改善时延长当前运动。改向方向本身可随机。它是待检验的模型假设，不预先保证会聚集。

一个可实施的候选闭合为：传感器得到 z，两个滤波记忆 m_f、m_s 满足 τ_i dm_i/dt=z−m_i，且 τ_f<τ_s；定义 q=(m_f−T*)(m_f−m_s)/ΔT²，再设有界正转向率 λ=λ0 exp[β tanh(q)]。q<0 表示朝舒适温度改善。舒适带内部是否降低灵敏度，在初始模型约定中固定，避免事后调到“好看”。

传感噪声以固定物理采样周期的独立高斯误差起步，再加入有明确相关时间的 OU 噪声。数值减小 dt 时不增加物理传感器的独立观测次数。不得直接对无限带宽白噪声求温度导数。

理论任务：写出含朝向和记忆的随机动力学；先推导无噪/弱响应等可处理极限，再求或估计粗粒化漂移和扩散。记忆存在时，位置本身通常不构成闭合 Markov 过程，不能不加说明直接套只含位置的 Fokker–Planck 方程。检验近舒适区是否出现恢复性漂移，再讨论分布宽度；不预设必然高斯。

对照：固定随机运动；同速去掉趋势记忆；无测量噪声；仅用于性能上界参考的理想方向感知。理想感知对照明确标为额外信息，不与局部策略混为相同能力。

交付：轨迹之外必须有温度误差分布、首次进入舒适区的时间分布、长期驻留比例、噪声—记忆参数图，以及一项解析极限与数值比较。这一阶段形成初步结论，但不承担软体身体或机械耗散的最终结论。

### M2：规定形变身体 + RFT + 实际局部测温

从 PR 提取阻力平衡的思想，在独立模块重新建立：材料弧长坐标 → 连续形变 → 局部速度 → 阻力 → 自由游动的平移/旋转 → 头部测温。

优先规定曲率/切角并重建固定弧长中心线；幅度、频率、偏置具有有限响应时间和变化率。几何时间导数必须包含相位与所有随时间变化的形状参数。控制器只改变波参数/弯曲驱动，不直接设置身体朝向与位移。与 M1 相同的行为意图通过有限时长的转弯驱动实现，不瞬间旋转整个身体。

物理耗散采用局部线性阻力模型：

\[
P_{\mathrm{drag}}=\int_0^L(\xi_\parallel v_\parallel^2+\xi_\perp v_\perp^2)\,\mathrm ds,\qquad
W_{\mathrm{drag}}(t)=\int_0^t P_{\mathrm{drag}}(u)\,\mathrm du .\tag{1}
\]

速度相对静止介质，阻力系数是单位弧长的系数。W 累加不截断；有限能量预算若要研究，另设状态与统一终止行为。ξ⊥/ξ∥ 的选值需要与介质假设/文献一致，不能把 1.4 当作所有环境通用常数。

验证先于趋温：无形变不推进；合力/合力矩残差；旋转/平移协变；对称性和适用条件下的各向同性极限；完整几何有限差分速度与实现速度一致；改变波参数也产生相应功；时间步/弧长网格加密；总弧长误差与实际位移。奇异求解应报错并保存参数，不以零运动吞掉失败。

尺度校准后再接 M1 控制器。记录命令、有效驱动、形状、真实局部温度、噪声观测、记忆、速度、功率和累计功。先测试固定波形游动，再做转弯，再做趋温。

交付：通过验证的身体推进/耗散模型；在噪声梯度中的趋温统计；性能与机械耗散的比较图。此阶段可以讨论“形变与耗散”，尚不能讨论弹性刚度的因果影响。

### M3：弹性身体、主动采样与能耗的正式研究

这是正式目标的一部分，不是把点模型当终点后的附带扩展。采用二维不可伸长离散弹性杆/弹性细丝，以主动弯矩或定义清楚的驱动作用于身体，求解弹性、约束张力与介质阻力共同决定的形状。先只保留弯曲弹性，不立即上三维完整 Cosserat 杆、接触、自碰撞或流体网格求解。

必须区分：介质耗散、弹性储能、主动驱动做功以及可选内部耗散。在无外部边界做功的约定下，应验证对应的功率平衡：

\[
P_{\mathrm{act}}=\frac{\mathrm dE_{\mathrm{el}}}{\mathrm dt}+P_{\mathrm{drag}}+P_{\mathrm{int}} .\tag{2}
\]

这是要求实现满足的模型记账关系，不是把所有机械功称为代谢能。若选随时间改变的偏好曲率，须计入其参数变化对应的驱动功，不能直接套与主动弯矩不同的能量定义。

先验证关驱动后弹性能衰减/耗散平衡、已知小形变弛豫或受迫响应、空间时间收敛。必要时采用半隐式/隐式积分，避免弹性数值刚性把计算成本误当作物理限制。

随后只围绕一个主实验：不同测温噪声下，头部摆动/身体柔软性如何改变趋温效果与机械耗散。初期固定驱动协议改变刚度，研究被动响应的因果；之后才允许各刚度重新调参，研究可达到的性能。这两类比较必须分开。

主动采样的机制对照可以在相同已生成轨迹上先比较头部与参考点的虚拟传感结果（仅检验信息变化），再做真实闭环控制；虚拟参考点传感只是机制对照，不作为真实线虫能力。比较时保持传感器数量、噪声模型和采样频率一致。

交付：至少一项身体因素如何改变含噪趋温的解释，以及相同时间窗下的机械代价比较。改善、无明显改善、只在某尺度范围内改善，都可形成结论。

### M4：核心结论完成后按需扩展

弯曲等温线 → 缓慢移动的舒适区域/随时间改变的场；先只增加一个复杂性。要区分自身移动导致的温变与背景升降温，单个局部温度时间序列存在信息歧义，应明确增加了哪种观测或环境假设。

强化学习可作为同等信息约束下的后续性能对照，不是当前主线前置项。多体、信息素、课程学习大矩阵和完整 UI 重写暂缓。

## 6. 统计设计、无量纲量与停止准则

先聚焦两个轴：噪声与记忆；身体阶段再聚焦噪声与一种身体/驱动参数。避免把所有参数做笛卡尔积。

| 量 | 作用与限制 |
|---|---|
| σT/ΔT | 测温噪声相对舒适温度半宽 |
| Gv0τm/σT | 在朝梯度运动、方向短时保持等近似下，一个记忆时间的温度信号/噪声尺度；不是普适判定阈值 |
| λ0τm、τη/τm | 转向、记忆与噪声相关时间的配合 |
| GL/ΔT、fτm | 身体跨越的温差尺度、摆动与记忆的关系 |
| Sp=L(ωξ⊥/B)^(1/4) | 弹性阶段的黏性—弯曲时间尺度组合，B 为弯曲刚度；按实际杆方程核对定义 |

σT=0 单独处理，不计算含 σT 分母的量。v0 在点模型是规定速度，在身体模型应选明确定义的参考游速，不能把策略变化后的所有速度差藏进归一化。

性能指标：首次进入舒适区时间（未到达者右删失，同时报告到达率）、固定时间内舒适区驻留比例、真实温度误差的 RMS/分布、沿梯度的漂移与波动。稳态分布须检查不同初态和时间窗口的一致性，不能仅因轨迹变平稳就认定已达稳态。

能耗指标：固定观察时长的平均功率和累计功、搜索阶段到达前耗散及对应成功率。比较性能—能耗的 Pareto 图或相同性能下的耗散，不急于加权成一个奖励。驻留阶段不采用“净位移能耗比”，因为良好驻留时净位移可能接近零。

边界：M1 可在一维有限区间用明确反射条件求解，同时增大区间检查舒适区附近结论是否受边界影响；二维沿等温线方向可周期化。RFT/弹性身体初期在足够大域做有限时间实验，边界触碰记录为截断，不能把瞬间回移当真实运动；需要壁面时另建接触模型。线性温度场沿梯度方向不能直接周期拼接，否则会出现温度跳变。

计算预算：点模型小规模预扫可用约 5×5 参数点、每点 20 个种子，仅用于定位区间；正式结论加样到预先指定的置信区间精度，未达精度则报告不确定性。身体阶段先计时 1–3 个代表配置，估算成本后选 5–10 个机制明确的配置起步。按独立轨迹/种子重采样估计误差，不能把同一轨迹的帧当作独立样本。

可用默认工程验收目标：关键确定性观测量在连续两级 dt、ds 加密中相对变化约 2% 以内；接近零的量用有物理尺度的绝对误差。统计结论还须不因加密而改变。阈值是拟议验收标准，须结合模型和实际误差预算确认。

## 7. 新代码结构与迁移原则

第 0 阶段已经新增独立 `src/thermotaxis/`，旧 `程序/` 未搬动、未删除；实施分支为 `codex/phase0-foundation`。当前新核心只包含研究契约、配置、局部传感器边界、结果记录和命令行入口，尚未实现趋温运动。

```text
src/thermotaxis/
  fields.py          # 真值温度场；控制器不得直接访问
  sensors.py         # 采样位置、测量噪声、物理采样时钟
  controllers.py     # 记忆与可解释控制；只接收允许的观测
  bodies/
    persistent.py    # 最简持续随机运动
    prescribed.py    # 固定弧长的规定形变
    elastic.py       # 主动弹性细丝
  media.py           # RFT 阻力及功率
  simulation.py      # 独立物理/感知/控制时钟
  metrics.py         # 真值评价、删失、耗散与统计
  experiments.py     # 配置、种子、运行与记录
configs/
analysis/
tests/
docs/
```

这是按研究职责划分，不要求第一阶段把每个文件做成通用框架。控制器不能拿到整个环境对象。绘图只读取保存的结果，UI 最后作为配置/回放入口。几何、传感位置和绘图必须使用同一身体状态，避免“画出来的形状”与计算阻力的形状不一致。

## 9. 文献入口与用途

- [de Gennes, 2004, Chemotaxis: the role of internal delays](https://www.phys.ens.psl.eu/~hakim/STATBIO16/degennes04ebpj.pdf)：借鉴从带记忆的随机运动到平均漂移的推导方法；对象是细菌趋化，不能直接作为线虫趋温机制的实验证据。
- [Wiggins & Goldstein, Flexive and Propulsive Dynamics of Elastica at Low Reynolds Numbers](https://arxiv.org/abs/cond-mat/9707346)：弹性恢复与黏性阻力的时间尺度、受迫细丝和推进，作为弹性阶段的理论入口；其具体驱动边界条件不等同于本项目的自由游动全身驱动。
- [Luo et al., 2014, Bidirectional thermotaxis in C. elegans](https://pmc.ncbi.nlm.nih.gov/articles/PMC3932917/)：用于后续核对真实生物的不同温区与导航策略。当前检索得到论文信息，但全文网页出现访问检查；本计划未据此宣称已复现该实验或采用了已核实的具体生物参数。

以上是方法起点，不构成创新性评估。正式确定研究题目后，还需针对“含噪测温—主动采样—柔性耗散”做聚焦文献检索，再限定本项目声称的新发现。
