# 研究进展与整体计划（组员版）

更新：2026-10-25。

## 我们研究什么

线虫只依靠运动中获得的局部温度信息时，真实神经连接与记忆机制，能否帮助它更容易学会趋温？这些机制又怎样与头部采样、转向速度和身体响应配合？已有软体运动平台作为基线保留，新研究在独立模块中开展。

## 目前做到哪里

- **已实现：数据与二维任务。** 已导入真实线虫连接数据，建立持续推进、头部摆动测温、连续转向的二维等温追踪场景。当前二维实验采用规定运动学，完整弹性身体尚未接入这组神经比较。
- **已实现：可学习的普通网络基准。** GRU是一种能够保存历史信息的通用循环神经网络，GRU16的内部记忆状态有16个分量。它通过模仿示范动作学会基础追踪，提供比较基准。
- **已完成：数据量、优化次数和连接布局比较。** 同样32条示范轨迹、2048次参数更新，真实图和三张重排图都能学会静态追踪；8条示范时GRU16表现更好，目前没有真实连接更省样本的证据。这里衡量的是监督示范效率。
- **已完成：动态温度场与10张重排图复检。** 36组训练记录、38组评估均已完成。快速温度波下真实图平均追踪77.07%，新增重排图中三张平均值高于它，GRU16为96.41%。早先相对三张重排图的优势未扩展为稳定领先。
- **部分实现：物理响应比较。** 已用冻结网络比较执行响应、平滑与测温噪声。有限响应能平滑动作，也带来迟滞，目前没有普遍性能收益；不同物理条件下重新训练的系统比较尚未完成。

“真实图”采用真实连接布局，神经动态、观测入口和行为读出仍是简化设计。当前已有结果属于仿真和监督模仿学习，强化学习交互效率、生物机制复现及真实软体身体趋温仍待验证。

## 整体研究计划

1. **整理连接结构比较。** 本轮10张图评估已经完成，保留全部图及失败记录，作为后续机制分析依据。
2. **解释机制。** 固定其余条件，分别消融记忆时间常数、感觉适应、连接符号和回路组成，寻找影响学习与动态迁移的具体因素。
3. **检验神经与物理条件的配合。** 将选定机制与转向响应、采样和噪声条件交叉比较，分别记录平滑收益和延迟代价。
4. **进入身体与学习效率研究。** 逐步接入已有RFT身体模块，再开展弹性身体、身体反馈以及统一预算下的强化学习比较。

实验不预设真实连接一定更好。目标是解释哪些信息处理与结构特征在什么条件下有效，以及它们怎样与身体运动共同影响趋温。
