# 阶段研究进展与后续入口（组员版）

更新：2026-10-25。本轮阶段性结束，实验、复查与材料已整理。

## 我们研究什么

只依靠运动中获得的局部温度信息时，真实线虫连接结构与记忆机制，是否有助于学会趋温？它们怎样与主动采样、转向响应配合？旧软体平台保留为基线，新研究在独立模块中推进。

## 本轮完成了什么

已实现“舒适带外随机出发 → 找到温区 → 稳定等温追踪 → 场变化后恢复”的完整导航任务，并完成接口、感觉适应和闭环学习比较：105组共同示范初始化＋PPO训练，另复用相同示范检查点完成42组几何控制复查。所有图、种子和失败预检保留。

原60°场转向会让部分已沿旧等温线走远的个体，因剩余时间不足而无法恢复。原结果保留为压力测试；修正为15°并使用32个新病例后，同一局部参考控制器完整成功率从59.38%升至100%。

## 目前看到什么

以下是几何控制复查中、相同最终预算下的完整导航成功率，先按病例平均，再按三个训练种子平均：

| 模型 | 完整成功率 |
| --- | --- |
| 真实连接掩码模型 | 59.38% |
| 10张重排图的平均 | 47.92% |
| 隔离节点模型 | 22.92% |
| GRU16通用记忆网络 | 100% |

真实图均值高于所测每张重排图，但种子波动较大（46.88%—81.25%）。而且这种差异在共同示范初始化后已存在，PPO阶段的额外增益没有更高，因此目前是条件性的结构线索，尚未证明真实图提高强化学习样本效率。

另一项诊断发现：当前简化模型限制为AFD输入、RIA输出时，对微小温度变化的转向响应很弱。它的低分不能直接用于否定真实生物回路。独立运动反馈源模型能产生更长前行和定向收益，但该结果与8节点掩码比较分开解释。

## 状态与后续

- **已实现并完成本轮检验：** 完整导航、路径依赖检查、105组因素比较、42组几何复查、专项机制与迁移干预，代码完整测试225项通过。
- **部分实现：** 有文献时间尺度依据的AFD阈值适应，以及独立论文运动反馈模型。主8节点仍是统一速率动态和工程感觉接口，未完成细胞／突触数据校准。
- **后续入口：** 优先校准受限接口下的感觉—动作传递，再用更多独立训练种子和全新图／病例确认条件性差异；身体响应交叉与RFT／弹性身体接入仍属后续。避免只扩大任务难度来寻找高分。

当前结果属于规定运动学仿真、共同示范后的学习比较，不是活体实验或完整软体力学结论。
