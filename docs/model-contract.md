# 第 0 阶段模型约定

状态：研究工作约定 v1，2026-09-22。配置模式版本为 `schema_version: 1`。

## 研究问题

研究一个仅通过头部局部含噪测温、短期记忆和自身运动获取信息的个体，怎样找到并维持在给定舒适温度附近；在引入柔性身体后，研究主动采样、趋温表现与机械耗散之间的关系。

点模型只承担初步机制探索。规定形变身体和弹性身体分别承担推进/耗散与柔软性结论。

## 第一个工作场景

- 二维、单个个体、静态线性温度场。
- 给定偏好温度 `T*` 和舒适半宽 `ΔT`；舒适条件为 `|T-T*| <= ΔT`。
- 均匀牛顿黏性介质，温度场不受个体扰动，阻力参数暂不随温度变化。
- 初始物理对象是受线虫启发的游动体，不宣称等同于培养皿表面爬行。
- 基准参数是可复现的工作值，还不是经过文献标定的真实线虫参数。

介质选择仍是研究决策。如果最终研究表面爬行，应替换身体—介质模型；局部感知、统计指标和实验记录接口可以保留。

## 因果链与信息边界

正式仿真必须保持以下顺序：

```text
温度真值场
  -> 头部传感器（固定采样时钟 + 测量噪声）
  -> 控制器可见的 SensorReading
  -> 控制命令
  -> 有限响应时间的有效驱动
  -> 身体形变
  -> 介质力与运动
  -> 新的采样位置
```

控制器第一阶段只收到 `temperature_K` 与 `sample_time_s`。以下数据可供离线评价，但不得进入控制器：

- 温度场对象、真实梯度或邻点温度；
- 个体的绝对位置；
- 舒适区域或所谓“最佳点”的坐标；
- 无噪声真实温度；
- 未来的温度或轨迹。

以后若增加本体感觉或身体多点感知，需要提升配置模式版本，并在实验中与单传感器条件分开比较。

## 单位、坐标和时间

- SI 单位：米、秒、开尔文、千克、帕秒、焦耳。
- 位置采用二维笛卡尔坐标；温度真值第一阶段为连续解析函数，不对连续位置取整。
- `physics_dt_s`、`sensor_dt_s`、`control_dt_s` 分开配置。传感与控制周期必须是物理时间步的整数倍。
- 减小数值物理时间步不会增加单位物理时间内的独立测温次数。
- 环境、传感噪声、初态和控制随机性使用四个独立随机源。任何模块不得重设全局随机种子。

参考配置中的 Reynolds 数为

\[
\mathrm{Re}=\frac{\rho U L}{\mu}=0.002.\tag{1}
\]

这支持把低 Reynolds 数作为第一工作假设，但不等于已经验证后续 RFT 阻力系数或真实生物场景。

## 机械量的记账

以下量必须分开：

- 介质中的瞬时耗散功率与累计耗散；
- 弹性阶段的储能；
- 主动驱动做功；
- 可选的有限能量预算和终止状态；
- 趋温任务的行为指标或学习奖励。

累计机械耗散不可因能量预算归零而截断。没有弹性身体时，只能讨论规定形变下的介质耗散，不能声称已经测得柔软性代价或代谢能。

## 可复现记录

每次新核心运行至少保存：

- 完整解析后的配置和配置 SHA-256；
- Git 提交、Python 与平台信息；
- 每类随机源的种子；
- 真值评价与控制器观测分开的结果；
- 时间步、采样周期、控制周期及相应计数；
- 模型版本和结果类型。

`phase0_contract_probe` 只检查基础设施，不是趋温实验，输出中必须标记 `scientific_result: false`。

## 阶段 1 前的进入条件

- 参考配置在两次运行中产生逐值相同的 phase-0 结果；
- 更改传感器种子只改变测量噪声，不改变真值场和派生物理尺度；
- 非法时钟比例和特权观测配置会被拒绝；
- 命令行结果包包含配置、清单和结果三个文件；
- 旧平台仍能运行，新的研究核心不依赖 Streamlit 或 PyTorch。

阶段 1 的第一项实现将是持续随机运动点模型、双时间尺度温度记忆和有界转向率；第 0 阶段不预先写入这套行为规则。
