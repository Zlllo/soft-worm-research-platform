# 从完整命名网络接入身体：接口阶段与后续实验

后续执行更新：已完成[302神经元持续C1动态与身体传递](reports/full302-c1-dynamics-2026-11-05.md)，4个主要条件和3次步长复查实际运行，项目221项检查通过；实际温度和机械反馈闭环仍未完成。以下保留接口阶段的设计与验证快照。

日期：2026-11-05。**本阶段已完成完整连线组装和独立肌肉驱动接口；302个神经元的动态仿真尚未执行。** 后续主规格采用all302，real8只保留为历史基线。

## 为什么先改身体接口

原连接数据覆盖302个神经元，但此前窗口策略显式选择8个节点，Boyle身体只接收总体驱动和头部偏置，运动来自身体内置的简化回路。因此，把控制器换成302节点再压成这两个量，仍没有检验完整的神经—肌肉作用。

本次新增路径为：

```mermaid
flowchart LR
  N[302个命名神经元] --> C[保留解剖掩码的神经肌肉连接]
  C --> M[95个命名体壁肌肉]
  M --> P[明确声明的二维空间投影]
  P --> B[48段背腹肌肉驱动与身体物理]
  B --> S[实际形状和局部应变]
  S -.待接入.-> N
  T[头部实际温度] -.待接入AFD.-> N
```

实线中的连线和接口已可调用；当前AS2单细胞输入是人为指定的代数脉冲，不包含神经元膜动态。虚线的感觉、神经动态和反馈仍待实现。

所有矩阵采用`[source,target]`。EM权重保留为解剖数据；函数要求调用方显式提供功能效能，不自动把数量当电导。原473细胞中的其他76个非体壁肌肉／非神经元细胞未接入本分支，不能称为全部细胞仿真。5对神经肌肉gap和肌肉间gap已导出，但当前代数脉冲没有动态实现它们；这需要肌肉膜电位，不能用实际应变替代电压差。

## 身体接口已怎样改变

新增独立的`BoyleMuscleBody`与生成程序；原worker、原BoyleBody和全部旧实验不变。新接口接收48×2个背腹肌肉的滤波前驱动，原简化运动神经元更新不再调用，没有隐藏的前行节律或头部偏置。

保持Boyle原有肌肉低通和力学。驱动为无量纲有符号量，范围[-1,1]；它不是膜电位、钙浓度或肌肉力。物理中的主动收缩使用肌肉状态正部，负驱动只使状态降低，不能解释为负的主动肌肉拉力。后续若c302已产生肌肉钙／激活，须先确定转换，避免无说明地叠加两套肌肉响应延迟。

每个1ms刻度先完成物理步、读取实际几何，再更新驱动和肌肉滤波；新肌肉状态作用于下一物理区间。兼容数据包原`neural96`字段在新后端中代表指令，构建记录明确标注；新保存结果使用`commanded_drive`命名，不能将它画成302神经元电位。

### 二维身体还会丢失什么

95个命名肌肉不能仅按数量与96个有效力学元件配对。当前提供一个**临时、显式命名**的投影：同序号左右肌肉取平均，作用于相邻两段的同一背／腹侧。序号仅用作名义纵向位置，不是实测附着几何；MVL24缺失位置保持零贡献，分母仍为二。

$$u_{2(r-1),s}=u_{2(r-1)+1,s}=\frac{a_{sL,r}+a_{sR,r}}{2},\qquad s\in\{D,V\}.\tag{1}$$

这个95×96矩阵的实际秩为48。同序号左右肌肉的差分完全不可见，二维身体也不能表达扭转和出平面运动。这是身体降阶造成的信息损失，不是神经网络节点数上限。当前可以研究平面内的驱动、形变、速度和采样；若要解释左右肌肉的不同作用，应采用实测肌肉附着映射与三维身体参照。

## 实际验证结果

- 新接口9项针对性检查通过，包括命名顺序、缺失连接保护、投影丢失信息、零输入、滤波响应、分块推进和重置。
- 原简化运动网络的输出逐1ms送入新接口，共3秒、3000次更新。身体姿态、肌肉状态、应变反馈和侧边长度与原worker逐点完全相同，最大绝对差均为0。这检验了接口替换对相同驱动的兼容性。
- 五个独立2秒探针完成：零驱动、头部背侧、头部腹侧、双侧共激活、AS2命名连接代数脉冲。全部几何与求解器时钟检查通过。
- 零驱动最大曲率约7.46×10⁻¹² m⁻¹；头部背／腹输入的最大曲率均约2034 m⁻¹，末态头部横向位移分别约+9.54／−9.54 μm。AS2脉冲经真实连接掩码产生6个非零有效驱动通道。该脉冲效能人为设定为0.2，只检验传递，不能作为AS2生理响应。
- 项目`tests/`共219项通过，14条已有依赖弃用警告。没有新增神经训练，也没有把规定驱动的运动算成完整网络行为。

重新核查c302固定源码还发现：`parameters_C1.py`的多个突触参数明确标为`BlindGuess`；`c302_Full.py`含PLM刺激和5pA的`unphysiological_offset_current`。因此“直接运行Full示例”仍不等于真实全网络。主实验将显式登记参数来源和未定项，移除示例刺激，另设刺激阳性对照。C1是可执行的第一层动态模型，不是302个细胞各自电生理均已校准。

## 下一阶段：直接推进all302动态，不再追加real8训练

机器可读主规格见[full302-body-contract.json](../configs/neuromechanics/full302-body-contract.json)。实施按三个有明确验收条件的步骤进行：

1. **302神经元＋95肌肉的持续动态。** 为c302生成固定Cook数据入口，逐个核对302和95名称；连接存在性、化学符号／效能、gap导电、单细胞参数分开登记。先做恒定背景与短脉冲，不训练导航。无来源的符号和参数保持显式假设，不默认全兴奋。验收包括孤立单细胞、神经肌肉传递、肌肉电耦合与无示例电流对照。
2. **神经活动接身体。** 将肌肉电位／钙转换为有界驱动，登记增益、静息值和饱和；先检查小幅肌肉响应及平面恒温运动。神经和身体均保持持续状态，做交换步长检查。前行、倒退和转向分别记录；没有自主运动时定位失败层，不通过隐藏节律补成成功。
3. **感觉和反馈闭环后再比较缺失回路。** 实际头温只进入声明的温敏细胞；形变反馈进入声明的本体感觉目标；指令副本作为另一个条件。主比较从同一302模型删去选定的中间／命令模块、或关闭指定反馈，并保持肌肉与身体一致。real8只作旧结果参照；它缺少独立的完整运动层，不能把它不能驱动95肌肉的失败当成公平容量比较。

先研究恒温运动与单次热扰动传播，随后进入短程线性温场。物理约束的生物解释对应三件可测事情：肌肉响应是否受长度／速度影响；实际形变是否改变神经反馈；改变反馈后是否改变真实采样轨迹。每项分别记录电位、肌肉、力学和感觉，不再用一个离线方向解码分数替代它们。
