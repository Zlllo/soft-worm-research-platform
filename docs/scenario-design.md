# 场景选择：用任务要求检验神经先验

更新：2026-10-24。二维规定运动的等温追踪基准、普通神经训练，以及真实化学连接与度保持重排的99组比较已经完成。记录见 [场景验证](reports/isothermal-scene-2026-10-24.md)、[普通网络](reports/neural-tracking-2026-10-24.md)和 [布局与优化](reports/tracking-topology-2026-10-24.md)。当前重点是固定接口并分别控制数据量、优化次数和容量；完整身体与动态温度扰动仍未实现，下列未实现部分仍是研究设计。

## 重新定位一维任务

局部测温、静态线性梯度和固定偏好温度下，已有双时标控制器能完成趋温。因此一维任务适合作为信息权限、时间记忆与训练可行性的基础检查，不能据其要求完整趋温回路，也不把反复提高对手工控制器的拟合分数当作主线成果。

环境复杂度和行为要求分别考虑。同样是线性梯度，“到达舒适区”和“持续前进并保持等温方向”对感觉—运动配合的要求不同。增加障碍、噪声或多热源并不自动让真实连接有优势。

|---|---|---|

| Luo et al., JEB 2006 | 线性、径向梯度中的等温追踪，以及叠加空间均匀周期温度变化后的轨迹 | 提供头部采样、连续转向和可解释扰动的任务依据 |

## 下一阶段优先顺序

### S0：基础能力与感觉重放

保留当前一维基准，但限制其职责。使用缓慢升降温、方向改变对应的温度历史、周期摆头对应的温度波形，核查输入与神经动态。训练/评价冷热侧分别报告，斜率与噪声留有未见条件。先消除零偏置tanh和零actor读出的初始化对称性问题，再作连接优劣比较。

对照至少包括普通记忆网络、低维可解释记忆控制器、真实候选与度数保持重排。可解释控制器包含已知任务先验，因此同时报告初始表现与学习增量。

### S1：二维等温追踪和主动采样

第一项主线行为任务：从偏好温度附近开始，保持推进，通过连续转向维持等温方向。先用静态线性梯度，随后用径向梯度检查沿弯曲等温线前进。此时不增加复杂障碍、食物状态或在线偏好学习。

把动作从一维反转率改为有界的连续转向驱动；身体运动生成实际头部测温位置。优先用已存在的规定运动/有限响应接口，不立即添加弹性材料模型。若先用二维运动学近似，结果必须注明，不能当真实软体力学结论。

| 对照因素 | 条件 | 要解释的差异 |
|---|---|---|
| 测温位置 | 身体中心、实际摆动头部 | 主动采样是否提供有用的时序信息 |
| 运动相位信息 | 不提供；提供所有模型相同的内部驱动相位 | 感觉与自身运动的配合是否有帮助 |
| 相位配合 | 正确相位；预定打乱相位的干预 | 收益是否依赖温度信号与运动的时间关系 |
| 执行响应 | 相同范围下的快速、有限响应 | 神经动态与身体响应是否匹配 |
| 控制结构 | 简单记忆、相位相关的可解释控制器、GRU、真实候选、重排 | 生物候选是否提供额外收益，以及它是否可被更简单机制解释 |

每个结构比较中，观测、驱动范围、前进规则和奖励保持相同。头部或中心测温是独立的实验条件；相位反馈属于明确新增的信息权限，所有模型一致提供。不得给某个模型真实梯度、位置或等温线方向。

温度误差之外，记录连续追踪时长、沿等温方向的前进距离、方向误差、过度转向与中断次数。保持非零推进或另设前进要求，避免静止获得高分。真实梯度和等温线方向只用于离线评价。最初不把未标定机械耗散写成代谢代价。

### S2：文献中的可解释动态扰动

Luo 2006在径向温度场叠加空间均匀正弦温度变化，报告了花状、环状轨迹。可选原始实验条件为40K/m空间梯度，加0.05K振幅、60秒周期；另有0.1K振幅、120秒周期条件。这些参数有文献来源，不是为了突出模型优势临时增加的地图难度。

这里温度波动会移动实际等温线，不能把所有时间变化都当作应被忽略的噪声。须明确任务是跟踪瞬时等温线，还是检验特定感觉—运动机制产生的轨迹；两种结果不能混为“成功率”。若两种环境变化在可见观测下无法区分，任何网络也不能凭空识别，需要先分析可辨识性。

## 参数与统计约束

普通网络的基础场景指标已接近上限，下一项应比较多个训练数据预算的学习曲线，配合噪声、头摆频率与曲率迁移，避免只比最高分。现有频率和半径检查是事后探索；后续正式测试需重新留出场景与种子。频率迁移中工程教师窗口随已知频率保持两个周期，网络窗口固定4秒，比较须说明先验差异。半径条件仅统计圆形场。相位打乱支持当前冻结模型利用相位，不能证明所有无相位策略均无法追踪。

摆动位移乘以梯度，决定可采样温差信号的量级。先计算该量与传感噪声之比，再选择噪声扫描；不直接沿用一维任务的0.05K噪声。时间步加密不能增加独立测温次数。

培养温度、偏好学习和进食状态另行研究。若加入它们，目标与控制器状态需一起定义，不能只添加一个情境标签而仍用不变的旧奖励。

场景和评估指标在训练前确定。保留简单条件、可能不利于生物先验的条件及未见条件。参数匹配与计算预算分别报告；最终表现接近时重点看学习曲线、训练失败比例、身体参数变化后的迁移，而不只比较最高分。
