# 研究主线：神经回路先验如何影响局部感知趋温学习

更新：2026-10-25。本文件记录当前研究方向，后续实现与结果需要对应其中的问题；探索结果不必支持原先假设。

推进方式：完成验证后自行进入与主线有关的下一项，不按阶段等待用户确认；方向调整以用户后续意见为准。

## 当前证据

- [路径依赖检查](reports/tracking-pathways-2026-10-25.md)：3次隔离节点拟合、144条新轨迹完成。冻结后隔离节点的动态均值从74.35%降至19.00%，隔离节点重训为14.28%；当前不能简单归因于绕过连接。用户要求优先核查[接口与功能机制](mechanism-audit-and-task-plan-2026-10-25.md)，任务调整先讨论再实施。
- [节点时间常数机制检查](reports/tracking-timescale-2026-10-25.md)：1248条冻结轨迹及6次真实图重训／72条评估完成。改变时间常数可改变连接布局排名；真实图0.9秒冻结动态约16.57%，重新训练后约71.46%。0.1秒重训存在静态拟合与闭环失败，该诊断保留；当前先核查接口与功能机制，再决定任务调整和后续训练对照。
- [数据量×优化×容量](reports/tracking-surface-2026-10-24.md)：126个评估端点完成。32条轨迹、2048更新时真实和三张重排图均学会静态追踪；8条轨迹时GRU16优于真实图，样本效率优势尚未出现。
- [物理响应](reports/tracking-response-2026-10-24.md)：336条冻结策略轨迹与12条步长检查完成。有限响应平滑动作，也增加迟滞；没有普遍追踪收益，未检验训练样本收益或能耗。
- [动态等温线](reports/moving-front-2026-10-24.md)：完成解析指标验证、全部三张重排与新病例复检。真实图在所测动态条件下平均好于重排，但GRU16更好，且部分训练种子重排领先。
- [相位复检](reports/moving-phase-2026-10-24.md)：544条冻结轨迹检验波动初相和前20秒后的表现。正式设计固定物理平均半径并保持初始中心温差可比；首个使目标坍缩的设计已排除并保留。
- [信息条件](reports/moving-front-identifiability-2026-10-24.md)：动态温变的空间／时间来源可能混同，主动转向和历史长度的作用需在明确环境变化族下检验。该线性分析不是神经网络性能下界。

[10张图扩展检查](reports/expanded-graphs-2026-10-25.md)已完成：36组训练记录、38组评估。新增7张图中三张平均动态表现高于真实图，GRU16仍更好；原三张图上的差异尚未形成扩展图集中的稳定领先。全部拟合与图保留。后续按计划开展机制消融，再比较神经机制与物理条件的配合。组员简版见[研究进展与整体计划](team-progress.md)。

## 核心问题

局部含噪感知下，真实线虫趋温相关神经连接与动态特征，能否提高学习效率？哪些特征产生作用，它们与身体响应及运动限制如何配合？

先比较性能，再解释机制，再研究身体因素对机制的影响。允许出现无优势、仅特定条件有优势、简化结构更有效等结果。不以某次训练最高分选择所谓真实回路。

## 当前工作边界

- 神经元范围、回路大小、神经动态和合理训练场景由公开证据与实验推进，不要求用户预判最优方案。
- 真实连接结构、简化神经动态、训练算法、行为读出分别记录，不能因为神经元名称真实就称完整生物复现。
- 固定偏好温度是任务共同条件。培养温度形成偏好记忆、饥饿调制、身体弹性与代谢尚未建模。
- 物理约束优先研究与感知和决策直接相关的作用，如执行延迟、感觉采样、运动反馈；暂不独立扩展全面材料参数扫描。
- RSI 和实际实验仍是老师提出的研究点，当前尚未具体展开，不擅自解释其定义或替代其研究目标。

## 数据与回路候选

使用 Cook2019 成年雌雄同体数据的 2020 年修正版，固定上游 commit 与 blob，见 `data/connectome/README.md`。已取得全部473细胞连接以及302神经元名单。

| 候选 | 范围 | 角色与限制 |
|---|---|---|
| AFD–AIY，4节点 | AFDL/R、AIYL/R | 有核心趋温证据；行为读出仍需工程假设 |
| 经典8节点 | 再加 AIZL/R、RIAL/R | 用于探索经典扩展，不能称各条件下均必需 |
| 扩展16节点 | 再加 AWC、ASI、AIA、AIB双侧 | 当前只完成结构核查；感知输入、状态调制与读出需要另行依据 |
| 302神经元 | 全部神经元 | 数据覆盖对照；不因数据完整就优先训练全网络 |

AFD/AIY、AIZ/RIA、AWC/ASI的作用依赖温度区间、行为类型和进食状态。2020年的实验将 AFD–AIY 描述为核心，将 AWC–AIA 纳入进食状态调制。RIA还涉及亚细胞局部动态，单节点模型不保留这些计算。

## 对照与结果权限

至少需要手工双时标记忆、通用记忆网络、随机稀疏网络、保持每个神经元度数的重排网络与生物候选。每个比较写明究竟改变什么。若gap、输入与读出固定，仅改变化学连接，只能解释化学布局的作用。

主要指标为达到预先规定行为水平所需的环境交互，配合完整学习曲线、初始表现与最终表现、训练失败比例、计算耗时和迁移表现。未达到阈值的训练记录为未达到，不随意赋予一个有限学习时间。

保持感知权限、动作范围、奖励、物理时长、训练与调参预算可比。参数数量、隐藏状态数量和计算量分别报告。不同训练种子与不同随机拓扑种子在正式阶段交叉比较；多个评估episode不能替代独立训练次数。

场景按机制假设构建，同时保留无需记忆的简单任务与可能不利于生物先验的条件。模型选择只用训练/验证场景；已查看的探索holdout不能再作为最终确认性测试。

## 实验顺序

1. 数据校验、候选回路可达性与可运行训练对照。
2. 可学习性核查：通用记忆模型与生物候选是否能表达并学会任务；必要时用已知双时标控制器提供监督探针，监督探针不作为RL样本效率证据。
3. 在已能可靠学习的统一条件下比较连接先验，增加参数匹配与随机图对照。
4. 消融时间常数、适应、连接符号与回路组成，解释性能差异。
5. 检验神经时间尺度与身体响应时间、感觉反馈之间的配合，逐步进入二维身体趋温。

第一批探索如所有网络均未学会，不将小幅排名解释为生物优势，也不直接扩大身体复杂度。

根据文献和用户对场景的调整，后续转向 [场景设计](scenario-design.md)：一维简单梯度保留为基础检查，主线优先发展二维等温追踪、头部主动采样、连续转向与有限执行响应。较复杂环境不是目的，任务与候选神经机制的匹配才是选择依据。

二维规定运动学场景现已实现，444条检查完成，见 [场景验证](reports/isothermal-scene-2026-10-24.md)。简单相位相关控制器可维持等温追踪。响应时间0–3秒在该场景验证中影响较小，不将其解释为物理约束提高性能。

普通神经控制器的监督模仿学习已完成，见 [训练与迁移记录](reports/neural-tracking-2026-10-24.md)。去均值且保留均值的 GRU16 在三个训练种子的基础评估中均达到100%追踪时间比例；这提供了任务可学习的基准。原始 GRU 和 MLP 的追加训练改善同时伴随更多数据和更新，不能只解释成访问轨迹示范的作用。较快头摆下 MLP 降至约39%，说明基础高分不能代替迁移检查。该普通网络批次验证176项通过；连接布局比较后完整验证182项通过。

## 连接布局比较的当前结果

99组数据预算×连接布局×训练种子比较已完成，另有9次固定数据延长优化对照，见 [布局、接口与优化记录](reports/tracking-topology-2026-10-24.md)。限制接口时真实与重排图在八个新病例上约32%，接近保持朝向对照；全节点可训练接口下真实图平均高于三张重排图，但接口同时增加参数，GRU16仍表现更好。

同32条轨迹增加到2048次更新后，全节点真实图、重排图11和GRU16的九个模型在同八个新病例均达到100%。512次更新下的低分不能直接解释为数据不足。全节点下真实拓扑的条件性差异值得继续检验，但尚无真实回路稳定提高样本效率的结论。

固定接口下的数据量×更新次数×模型容量比较已经完成，新增GRU2/3（57/94参数）作为71参数回路的容量参照，保留全部三张重排图。已有相同条件的检查点复用；所有拟合完成后才查看新病例9301—9304。该比较同样属于监督示范效率，不是强化学习交互效率。

## 对照要求与后续机制

正式对照以真实连接和度保持重排为主要拓扑对照，普通 GRU 为通用基线。共享温度/相位观测、历史窗口、动作边界、教师数据与初始化规则，交叉比较原始编码和保留均值的去均值编码。先按整条轨迹设置多个示范预算，分别记录轨迹数、物理时长、标签数和优化次数；不同随机图与训练种子分别重复。零偏置及零输出初始化造成的可训练性问题应先检验，不能把表达或优化失败直接解释为生物结构无效。

连接符号、时间常数及感觉适应单独消融，避免与拓扑一起改变。参数量、隐藏状态和计算量分别报告，不能把名义参数相同当成有效容量相同。追加访问轨迹示范另设同等更新次数的对照。监督数据效率和强化学习交互效率分开报告，目前尚无真实回路优势证据。

随后交叉比较执行响应和动作限制，同时记录平滑收益与迟滞代价；只有完成神经结构与物理条件的交叉对照，才讨论两者配合。RFT/弹性身体及机械耗散仍属后续阶段。保留简单梯度、可能无优势的条件及所有失败记录；已查看的探索场景不再作为正式确认性测试。
