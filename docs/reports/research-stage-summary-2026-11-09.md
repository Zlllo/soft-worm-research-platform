# 神经—身体机制研究：阶段总结与暂停交接

更新：2026-11-09。研究已按用户要求暂停；本次只整理、复算已有数据并公开同步，没有启动新实验、训练或下一阶段修复。

## 当前结论

目前已从早期8节点趋温基线推进到**302个神经元、95块具名肌肉与物理身体**的连续耦合模型。18个B类运动神经元原型能产生节律；肌肉能接收神经输出；身体形变能通过明确的反馈电流改变神经活动。尚未实现神经自主驱动的有效持续前进，也尚未进入这套完整身体模型的趋温训练。

当前主要问题有两层：**神经输出还未组织成有效的纵向肌肉推进波；完整系统的部分肌肉及反馈量仍对计算步长敏感。** 最新的局部积分修正通过了解析解检查，却未改善孤立肌肉整体响应的步长差，不能将它当作完整系统已经修好的证据。

## 完成度如何计算

近期机制阶段以五项等权验收计数，不含趋温学习，不代表已花时间或剩余工作量。

| 验收项 | 状态 | 依据 |
|---|---|---|
| 302神经元—95肌肉—身体接通 | 通过 | 具名连接、状态持续、因果时钟及实际身体接口检查 |
| B类节律及切断对照 | 通过 | 18/18有节律；切断AVB—B电耦合或移除主动钙电导后为0/18 |
| 神经—肌肉传递与身体物理对照 | 通过 | 同神经输入的NMJ对照；匹配肌肉驱动的相位与阻力对照 |
| 完整系统数值收敛与反馈因果 | 部分通过 | 反馈因果通过；完整系统数值收敛未通过 |
| 神经驱动持续推进及独立重复 | 未通过 | 速度与位移远未达到既定门槛 |

严格完成数仍为 **3/5，约60%**。完成了一个检查但结果未通过，不计为完成一个验收项。

## 已经验证的机制

### 1. 当前问题不能再简单归因于“只用了8个神经元”

当前完整分支包含302个神经元、95个肌肉细胞、4665条化学连接和1192对电连接。早期real8/classic8仅作为历史比较保留。

节点和解剖掩码完整，不等于每个细胞都已实现真实生理动态。18个DB/VB使用主动Ca/K工程原型，其余284个神经元仍使用通用C1动态；电导、释放范围、未确定的连接极性、肌肉读出和反馈增益都有明确建模假设。95块肌肉还经有损平面投影接入身体，不能研究完整三维扭转。

因此本阶段研究的是“真实解剖连接约束下，哪些动态和身体条件能产生运动”，还没有得到“真实网络优于重排网络”的完整身体对照结果。

### 2. 身体具备推进能力，肌肉之间的配合和介质方向阻力很关键

直接向肌肉施加相同幅度、频率和驱动总量的波形，经物理身体计算得到：

| 外部肌肉驱动条件 | 平均有符号速度（μm/s） |
|---|---:|
| 头到尾行波、原方向阻力 | 28.114 |
| 尾到头行波、原方向阻力 | −26.975 |
| 打乱纵向相位、原方向阻力 | 3.284 |
| 纵向同相、原方向阻力 | 0.495 |
| 相同行波、各方向阻力相同 | 接近0 |

这些是**规定肌肉波的物理对照**，不是神经网络自行产生的运动。它们确认当前身体可以把合适的肌肉配合转成推进；也显示单块肌肉收缩强，并不保证整体前进。方向阻力决定内部形变能否转为平移。驱动平方积分仅用于控制输入量，未测生物代谢能耗。

目前神经分支尚未形成达到推进门槛的有效肌肉配合。物理对照不能单独确定究竟是神经相位、肌肉幅度还是二者组合主导了失败。详见[完整网络与身体机制报告](full302-mechanisms-2026-11-07.md)。

### 3. 有神经节律，也有神经—肌肉传递，但还没有有效推进

AVB电输入下18个B类原型保持约1.9 Hz节律；切断AVB—B电耦合、移除主动钙电导、换成匹配接口的通用C1细胞，均未保持节律。其参数按孤立细胞条件选择，未做生理拟合，不能称为论文全部参数的精确复现。

相同神经波形下，NMJ电导从0.09增至0.9 nS，肌肉周期驱动标准差增大约509倍。这表明传递的工作范围非常重要，不能直接把电镜连接计数当作功能电导。

增强NMJ后的完整神经分支确实产生身体形变；实时反馈条件的历史平均前进速度约0.0213 μm/s，后4秒净位移约0.085 μm，远低于10 μm/s和20 μm门槛。后续步长检查未通过，因此这些小数仅保留为历史运行读数，不据此精确比较微小速度收益。详见[B类节律与NMJ报告](b-motor-mechanisms-2026-11-07.md)。

### 4. 身体反馈确实影响了神经，但未显示它能改善推进

两个初值种子的外部身体扰动后，反馈电流首次于2.002秒变化，B电位首次于2.003秒变化。冻结无扰动反馈电流可使神经、肌肉电活动保持原样；重放扰动产生的反馈电流可逐元素复现保存的神经与身体状态。12项因果与实现检查通过。

这建立了本模型内部“身体形变→感觉电流→神经活动”的因果通路。扰动后节律会改变，但只有4/18细胞满足预定峰序列配对条件，不能把结果概括成全体细胞同一相位变化。实时反馈相对冻结反馈没有表现出推进改善。反馈通路接通，与反馈已学会协调运动，是不同的验收问题。详见[身体反馈因果报告](b-motor-feedback-causality-2026-11-09.md)。

## 目前卡在哪里

### 完整系统对时间步仍敏感

同参数、同8秒条件下，将神经步长从0.025减半至0.0125，再减半至0.00625 ms，完整系统最细两档仍有未通过项：

- 反馈关闭时，肌肉钙和驱动的最大通道标准化逐时RMS差约为0.674、0.679。
- 实时反馈时，上述差约为0.570、0.376；协议上限均为0.05。此处数值按参考动态范围标准化，不是肌肉绝对浓度。
- 实时反馈B峰时最大差30 ms，高于10 ms门槛；反馈电流差也超过容差。

B频率、幅度、均值，以及本次容差内的身体形状和近零运动指标通过，但不能用这些通过项覆盖逐时肌肉和反馈的失败。身体交换仍固定1 ms，身体内部求解器尚未进一步细化。

白话说：把每秒计算的次数翻倍，有些肌肉和反馈曲线仍会明显变化。因此现在还无法可靠判断那些细微的波形差异有多少来自所研究的机制，有多少来自计算方法。原有六次完整运行和失败验收均保留。详见[收敛报告](b-motor-convergence-2026-11-09.md)。

### 局部积分已修正，但未解决整体响应问题

实际生成代码显示，原5个Ca/K门控及CaPool浓度使用显式Euler；直接写出状态导数后，生成了预期的指数更新。四个隔离版本为原版、仅门控修正、仅浓度池修正、两者合并，未混入生理调参、缓存刷新或离子同步修改。

12个解析控制中，合并版的门控误差约为2×10⁻¹³，浓度STATE误差约为1.4×10⁻²¹ mM，达到浮点精度附近。但12个同输入孤立肌肉主条件显示：

| 最细两档的肌肉电位RMS差 | 数值（mV） |
|---|---:|
| 原版 | 0.079889 |
| 仅门控修正 | 0.169512 |
| 仅浓度池修正 | 0.079006 |
| 合并修正 | 0.168627 |

四版的最细配对都在本组件容差内；合并版的电位步长差却约为原版2.11倍，钙和驱动差也约为2.1倍，未达到预先声明的总体改善要求。**局部公式算得更准确，并没有使复合肌肉响应的步长差更小。** 这组比较也不能反过来证明原版更接近连续系统真解，因为可能存在不同误差相互抵消，且输入保持本身也随步长变化。

另确认两项实现现象：保存端点的门控幂缓存对应最近一次更新前的状态；外向钙电流压力控制中，STATE截为零后，暴露的cai仍可短暂为负。普通12个肌肉主条件中STATE/cai完全一致且非负。尚未通过独立变体测定这两项对整体误差的贡献，不能把它们指定为完整系统的唯一原因。

合并修正没有替换冻结主模型，没有启动新的完整302/身体运行。详见[肌肉积分隔离报告](c1-muscle-integration-isolation-2026-11-09.md)与[独立复核](c1-muscle-integration-review-2026-11-09.md)。
