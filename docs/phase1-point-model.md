# 第 1 阶段：一维含噪趋温点模型

这一阶段只检验局部测温、短期记忆和持续随机运动能否产生趋温。点模型是身体模型之前的机制基准，不提供机械耗散或柔软性结论。

个体以固定速率 `v` 沿一维方向 `d = ±1` 运动，边界为反射边界：

\[
\dot{x}=vd.\tag{1}
\]

传感器按独立于物理步长的周期采样局部温度，并加入独立高斯误差。控制器知道给定的舒适温度 `T*`，但不能读取位置、真实温度场或温度梯度。每个测量值先转为温度误差 `e=|T_measured-T*|`，再进入快、慢两个一阶记忆：

\[
\tau_f\dot{m}_f=e-m_f,\qquad \tau_s\dot{m}_s=e-m_s,\qquad \tau_s>\tau_f.\tag{2}
\]

控制信号取 `I=m_s-m_f`。`I>0` 表示近期温度误差低于较长时间基线，即处境正在改善；此时降低转向率，延长当前方向的持续时间。`I<0` 时提高转向率。转向率采用线性响应、死区和上下界：

\[
\lambda=\operatorname{clip}(\lambda_0-gI_{\rm eff},\lambda_{\min},\lambda_{\max}).\tag{3}
\]

每个控制周期 `Δt_c` 发生转向的概率由连续时间泊松率离散化：

\[
P(\text{turn})=1-\exp(-\lambda\Delta t_c).\tag{4}
\]

物理、传感和控制分别使用 `physics_dt_s`、`sensor_dt_s` 和 `control_dt_s`。减小物理步长不会增加测量或决策次数。初态、传感噪声和控制随机数沿用相互独立的种子。

单次运行输出完整轨迹，并以无噪声真值计算首次进入舒适区时间、舒适区驻留比例和温度误差 RMS。每个物理步会沿反射前后的分段匀速路径计算它与舒适温度带的交叠，因此即使一步跨过整个舒适带，也不会漏掉首次进入和带内时间。驻留比例使用带内运动时间除以总观察时间，并约束在 `[0,1]`。在线性温度段上，温度误差平方按端点值解析积分，而非用单个端点近似整个物理步。

轨迹同时记录控制器状态、最近一次带噪读数、该读数的采样时刻以及当前物理步是否产生新样本，方便区分传感时钟和物理时钟。单次运行用于检查机制和重放轨迹；关于趋温效果的结论使用多种子配对集合与无响应对照。

## 配对集合实验

`phase1-ensemble` 以严格正整数 `replicates` 生成多个重复。第 `i` 个重复把传感、初态和控制种子分别设为配置基值加 `i`，环境种子保持配置值；有响应组和无响应组共享全部种子，对照组唯一的改动是令 `response_gain_per_K_s = 0`。这种配对设计减少了两组由随机初态、测量噪声和转向随机数差异引入的波动。

每组汇总到达数与到达率、仅对已到达轨迹计算的条件平均首次到达时间、限制平均首次到达时间、平均舒适区驻留比例、平均温度误差 RMS 和平均转向数。如果某条轨迹在观察结束前未到达，它不进入条件平均，在限制平均中则按完整观察时长计入：

\[
\bar t_{\rm restricted}=\frac{1}{N}\sum_{i=1}^{N}\min(t_i,t_{\rm obs}).\tag{5}
\]

当一组没有任何轨迹到达时，条件平均记为 `null`，限制平均等于观察时长。集合结果包只写入 `config.resolved.json`、`manifest.json` 和 `summary.json`。`summary.json` 保留每个配对的精简指标和种子，不保存完整轨迹，便于后续参数扫描。

示例命令：

```bash
python -m thermotaxis phase1-ensemble \
  --config configs/phase1_reference.json \
  --replicates 100 \
  --output-root results \
  --repository .
```

输出目录名包含重复数和配置摘要，例如 `phase1-reference-ensemble-100-replicates-<digest>`。在配置和重复数相同时，科学汇总内容可复现；`manifest.json` 中的创建时间用于记录运行批次，会随执行时刻变化。
