# 短期机制实验：神经通路、身体反馈与主动测温

日期：2026-11-03。状态：**实验设计，尚未执行下列新实验。** 接续[原研究计划](neuromechanical-research-plan-2026-10-27.md)、[已合并的PR #3](https://github.com/Zlllo/soft-worm-research-platform/pull/3)和[快速身体接口报告](reports/neuromechanics-stepper-2026-10-27.md)。

执行更新：上述状态保留方案起草时语境。三个阶段均已完成，见[本轮总览](reports/neural-physical-mechanisms-2026-11-03.md)、[神经通路](reports/pathway-stage1-2026-11-03.md)、[负载反馈](reports/body-load-stage2-2026-11-03.md)和[主动测温](reports/active-sensing-stage3-2026-11-03.md)。原定条件、负结果与补充分析分开保留。

这轮目标是解释：**选定神经通路的功能，是否依赖正确的传递动态、身体响应及运动—感觉配合；目前低分分别在哪一层产生。** 不把“真实图是否第一名”设为成功标准。现有真实图指保留部分解剖连接存在性的8节点速率模型，并非已校准的真实细胞动态。

建议先完成三个小实验，不启动新的大规模PPO，也不先接入302神经元。实验一解释现有网络，实验二解释身体反馈，实验三复用实验二轨迹，检查身体如何改变感觉计算。前两项为主要交付，第三项不等待完整趋温策略训练。

## 1. 为什么现在做这三项

| 已核实结果／论文依据 | 尚缺的原因判断 | 本轮实验 |
|---|---|---|
| PR #3：full补训读出有改善，restricted几乎无改善；没有等预算全参数续训对照 | 受限低分主要来自输出、输入投影还是内部传递？ | 一：分层续训与通路干预 |
| Wen：B型运动神经元参与局部弯曲耦合；Boyle：神经、肌肉、身体和负载共同决定步态 | 负载改变后，实时反馈是否提供固定驱动无法提供的补偿？ | 二：负载脉冲与反馈回放 |
| Hawk：AFD感觉适应与AFD→AIY传递调节可分离；Ji：AIY同时包含温度和运动状态信息 | 身体运动参考是否使局部温度变得更容易解释？ | 三：真实头部温度与运动参考的解码 |

Hawk等研究说明，感觉神经元有响应，并不保证下游传递或行为相同；它支持把感觉转导、突触传递和输出分开检验。[Hawk et al., 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC5806692/)

Wen等通过身体约束与细胞干预研究前后段弯曲耦合；Boyle等给出神经—肌肉—身体与环境负载相互作用的计算模型。我们将取用这条机制逻辑，不直接把模拟器通道置零称为某种真实细胞的消融。[Wen et al., 2012](https://pmc.ncbi.nlm.nih.gov/articles/PMC3508473/)、[Boyle et al., 2012](https://www.frontiersin.org/journals/computational-neuroscience/articles/10.3389/fncom.2012.00010/full)

Ji等的证据涉及RIM依赖的运动指令副本与前行持续性。它使“感觉输入还需要运动背景”成为值得研究的问题，但没有证明头部曲率就是该论文中的指令副本。[Ji et al., 2021](https://elifesciences.org/articles/68848)

## 2. 实验一：受限网络的信号到底卡在哪里

### 问题和假设

比较三个解释：原读出没有学好；温度／运动信号投影没有学好；内部回路动态没有学好。它直接补上PR #3的对照，最快得到可解释结果。

### 操作

从相同的BC检查点分别分出4个条件，保留full与restricted两种接口及种子7、17、27：

| 条件 | 可更新参数 | 检验什么 |
|---|---|---|
| 冻结基线 | 无 | 原模型状态 |
| R | 仅动作读出 | 输出层是否足以改善 |
| I+R | 输入投影与动作读出，内部连接和动态冻结 | 输入、输出适配是否足以改善 |
| All | 输入、内部回路与动作读出 | 允许内部功能改变后是否明显不同 |

critic不参与本实验。每个续训条件固定1024次更新、相同批量256与学习率0.003，使用相同教师样本索引；各条件从原BC独立开始，不能先训R再在其上继续All。总计24个评价条件，其中18次新增续训，6个冻结基线复用原检查点。参数更多是干预差别，结论不写成算法计算效率优势。

原24条教师episode用于续训，另8条只保留为旧数据诊断，因为它们也曾参与原BC。主要行为评价另生成32个未查看病例，平衡线性／径向场与冷热侧；在运行前固定病例和噪声种子。旧32病例只作配对回归，不当新泛化证据。保留15°条件，60°压力条件单列，不混合均值。

另给所有模型相同的温度阶跃与相位相关小信号，量级使用原探针的1、2、5 mK，记录AFD、AIY、AIZ、RIA和动作。续训后冻结模型，仅对数据中实际存在的AFD→AIY化学连接乘0或1；保持其余通路与参数不变，不添加不存在的边。

AFD→AIY干预先作路径敏感性检查。若动作幅值改变，再用独立校准刺激匹配读出总增益，检查相位、延迟与波形误差是否仍改变，避免把所有效应都归为简单放大。化学连接符号沿用检查点，不从EM数量推定兴奋／抑制。

### 主要指标与解释

同时报告动作误差、温度到各节点及动作的响应幅值／延迟、全程成功、线性场扰动后恢复。细胞活动是模型内部单位，主要使用同一模型内的配对变化。

- R有效：原模型至少已有部分可读出的任务表征。
- I+R比R明显改善：接口投影参与了瓶颈，不必先增加节点。
- 只有All有效：内部有效权重或动态需要改变；再用通路干预定位，不能只称“多训练就好”。
- 三种均无效：得到明确的受限结构／动态／优化疑点。随后用表达能力正对照区分，不能直接断言真实生物通路无用。

Hawk论文的生物启发在于区分“AFD响应”和“下游传递”。这里没有实测AFD／AIY活动拟合，故结果首先是对当前解剖约束模型的功能解释。

已有10张重排图及GRU检查点用于同刺激的冻结表征对照；第一批不重新训练全部图来寻找排名。若要比较续训后的布局差异，必须对所有10张图使用同预算，而不能只续训表现较弱的图。

**第一张图：** 4条件×2接口的改善量，以及AFD到RIA的逐节点响应。它应让人看出改善发生在哪一层，而不只是出现一条更高的学习曲线。

## 3. 实验二：实时身体反馈是否补偿物理负载

### 问题和假设

相同前进驱动，在环境负载改变时，身体形变会改变运动神经元输入。检验实时反馈是否帮助恢复弯曲传播；将这一部分与同一套机械方程在固定驱动下的响应区分。

### 操作

使用已经跑通的Boyle身体。前进驱动固定0.675、头部偏置为0、肌肉时间常数保持源模型值，环境恒温，暂时不接趋温策略。预热5秒后，给前1/4身体一个2秒的有效阻力脉冲，随后恢复。只按同一倍率改变该区段的纵、横向阻力，保持阻力比；不移动身体点、不重设姿态。

脉冲倍率固定为1、1.5、2：1是无扰动。它们是有效阻力模型的干预，并非对应已标定的琼脂浓度或黏度。脉冲在8个预先指定的步态相位施加，每条轨迹20秒。

主比较为：

| 条件 | 送入原伸展感受计算的信号 |
|---|---|
| 实时反馈 | 当前已接受身体几何重建的侧边长度 |
| 配对回放 | 对应无负载扰动运行在相同时刻的侧边长度 |

回放仍保留原神经与肌肉更新，只替换实际形变到伸展感受计算的输入。两组在无扰动时应复现到既定数值误差；不一致就先修复时钟、初态和回放接口。实际身体长度与用于神经更新的回放长度分别记录，不能把回放值冒充当前身体。

主设计2反馈×3负载×8相位，共48条20秒轨迹。重复的无扰动基线可以复用，不把它们计作独立重复。可增加一个因果延迟反馈条件，延迟取基线步态周期的1/4；它作为次要时序探针，须单独报告无扰动下是否已破坏步态。

本实验改变的是**运动模块内部的伸展反馈**。现有`ThermalBody(body_feedback=False)`只屏蔽控制器侧速度／曲率观测，不会完成此干预。

### 主要指标与解释

记录前后段曲率、传播相位差、神经／肌肉激活、速度变化和解除负载后的恢复。主要看扰动引起的波形偏差及恢复周期数，相对于各自无扰动基线计算；速度为辅助指标。

- 实时组比配对回放更快恢复，且存在相应神经／肌肉调整：支持实时形变反馈参与负载补偿。
- 两组恢复相近：该负载范围内，机械响应与原有驱动可能已足够；这是有价值的负结果。
- 延迟组额外受损：说明反馈的时间关系参与功能，而不只是多输入一个信号。
- 扰动前两组就不同，或只看到静止与运动的巨大差别：不能用于本轮补偿解释，先排查基线。

不以“关闭全部反馈后不能走”作为新主要结果，这一点先前已观察到。这里的新增信息是：**基础运动匹配后，神经反馈在负载改变时还做了什么。**

Wen论文支持B型神经元参与局部本体感觉耦合；本模拟器是简化等效运动单元，因此不据此推断真实B型细胞的定量响应。Boyle模型本身包含这类耦合假设，本实验是检查其功能后果，而非独立证明该假设。[Wen et al., 2012](https://pmc.ncbi.nlm.nih.gov/articles/PMC3508473/)、[Boyle et al., 2012](https://www.frontiersin.org/journals/computational-neuroscience/articles/10.3389/fncom.2012.00010/full)

**第二张图：** 负载脉冲前后的身体曲率时空图、前后段相位差和恢复曲线；并列实时与回放，显示物理与神经活动如何共同改变。

## 4. 实验三：身体运动是否让局部温度更有信息

### 问题和假设

同样的温度升降，可能来自沿梯度移动，也可能来自头部摆动。身体不仅限制动作，还决定感觉刺激的生成过程。检验当前身体的局部运动参考，是否帮助判断身体哪一侧更暖，以及负载改变是否破坏这种配合。

### 操作

复用实验二的身体轨迹；这些运行中没有温度控制器，改变温场不会反过来改变轨迹，因此可以离线重新采样，不再运行身体求解器。给定8个预先固定的线性梯度方向、梯度大小40 K/m，并分别加入固定随机种子的温度噪声。这里仍是感觉可用性实验，不是闭环趋温成绩。

从实际头部坐标采样温度，比较：

1. 头部温度历史，运动参考槽位置零。
2. 同一头部温度历史，加实际头部曲率及其因果差分。
3. 同一温度历史，加来自不匹配时段的运动参考，保留近似幅值／频谱，破坏对应关系。
4. 反事实身体中心温度，加相同实际运动参考，检查传感位置的作用。

曲率差分只能使用当前及过去样本；不使用离线Hilbert相位或未来平滑。主要条件不输入规定正弦相位。匹配／错配条件保留完全相同的温度和噪声序列；错配幅值与频谱必须实测，不能仅由构造方式假定相同。

要预测的量是“当前运动平面中身体轴的哪一侧更暖”，不将其混同于解剖的左右肌肉象限。标签由评价器根据温场梯度与实际身体朝向计算，梯度和朝向均不作为解码器输入。接近零横向梯度的样本按预先规定阈值单列，避免任意符号标签。

先用共同的因果局部回归正对照：在4秒窗口内，用常数、时间、曲率及曲率差分解释温度波形，再用得到的系数作方向解码；另用小型GRU检验非线性表达是否重要。所有模型有相同历史和信息权限。按完整身体运行划分训练、验证和测试，同一运行的所有温场方向与相邻窗口必须放在同一集合，避免泄漏。

正对照能读出信息后，再将同一温度与运动数据输入真实8节点、全部10张重排图及通用网络的冻结骨干，在AFD／AIY／RIA状态上拟合相同规则的简单读出，测信息到哪里减弱。实际曲率到旧相位输入槽位是工程投影，需要先做共同量级校准；不能把投影不匹配造成的失败解释成生物细胞不会计算。

### 主要指标与解释

报告新身体运行上的方向解码准确率、温度—曲率关系、不同负载下的变化，以及各神经层的可读出信息。错配首先测冻结解码器的依赖；允许重新拟合的结果另列，区分急性失配与信息本身不可恢复。

- 实际运动参考优于温度单独输入和错配参考：支持身体运动提供了感觉解释所需的参照。
- 负载同时改变曲率传播、头部温变与下游解码：建立物理约束影响神经计算任务的具体路径。
- 通用正对照可解码而RIA表征难以解码：将问题定位到当前神经实现，而非环境没有信息。
- 只有规定相位有效、实际曲率参考无效：说明工程相位接口不能直接替代真实运动感觉，需要重新设计。

Ji论文中AIY运动信号是指令副本，实验三输入的是身体形变反馈。两者分别命名；本实验若成功，支持温度与运动背景结合的计算作用，不自动复现RIM机制。[Ji et al., 2021](https://elifesciences.org/articles/68848)

## 5. 实现量、时间与完成标准

| 顺序 | 复用内容 | 需要新增 | 预计首次结果 |
|---|---|---|---|
| 一 | BC模型、教师缓存、诊断与评价脚本 | I+R／All同预算分支、新病例、通路干预 | 约0.5–1个工作日 |
| 二 | 已验证的Boyle工作进程和几何记录 | 局部阻力脉冲、1 ms反馈记录／回放入口 | 约1–2个工作日 |
| 三 | 实验二身体轨迹、局部温度采样、冻结神经模型 | 因果运动特征、分组解码、错配对照 | 约0.5–1个工作日 |

这是实现与排查时间估计，不是已经测得的总耗时。建议按3–5个工作日安排首轮，预留数值与接口检查。已有接口记录10秒模拟约3.76秒；据此，实验二48×20秒的单身体基准计算约6分钟，但新增记录、反馈路径、求解器开销均需重新计时。先运行一个短条件再确定批量预算。

实验二对典型无扰动与有扰动条件做耦合步长减半检查，尤其比较波形和恢复时序，不仅比较平均速度。若数值变化与反馈效应同量级，先处理数值误差。实验一保留全部训练种子，实验二的8个相位只代表同一模型内的初始条件变化，不当作8只生物个体。实验三按独立身体运行分组，不把大量重叠窗口当独立重复。

每项都在运行前保存条件表、种子、主要指标、分析入口和解释规则。报告所有分支；无效果、响应反向与数值失败都保留。第一轮不做大范围超参数搜索。

三项完成标准是各获得一项可核查的原因判断，不要求真实图胜出。若实验一续训未改善，但实验二、三明确显示实时身体反馈与主动测温的重要性，依然能解释现有模型缺失的功能环节。

## 6. 这一周暂不承担什么

不把Sibernetic或BAAIWorm作为本轮批量运行前提；沿用已跑通的快速身体，其他模型保留独立验证用途。不把反向波、负驱动或驱动关闭当作已经标定的倒退／停止动作。

RIM依赖的前行持续性是下一项合适的生物机制实验，但需要明确的运动状态转换。当前Boyle接口尚未验证倒退，故本轮不硬接RIM来演示该机制，也不把头摆相位当成运动指令副本。先完成上述信号与身体因果实验，再决定是否扩展RIM和命令回路。

本计划形成的解释链是：**通路是否传得出信息 → 身体扰动是否需要反馈补偿 → 实际运动是否改变感觉信息的可用性。** 之后才有依据选择要增加的细胞、动态或反馈通路。
