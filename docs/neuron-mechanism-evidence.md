# 神经动态与感觉接口：证据和建模假设

更新：2026-10-24。用于决定后续单因素实验，不把任何假设预先当成生物优势结论。

## 当前模型实际保留了什么

经典8节点模型保留选定神经元之间的解剖连接是否存在；化学效能与符号可训练，神经元采用统一速率动态。固定偏好温度、4秒历史、AIY的sin/cos运动相位输入和RIA输出均为任务或工程假设。模型尚未保留真实的感觉转导、突触受体、细胞内局部动态、培养温度记忆或完整运动状态回馈。

## 原始研究与适用范围

| 研究 | 直接证据 | 对当前任务的约束 |
| --- | --- | --- |
| [Ji et al., eLife 2021](https://elifesciences.org/articles/68848) | 正趋温中AIY同时表征温度和前行／倒退状态；RIM参与该运动状态反馈，去除RIM损害前行持续性 | 这种状态反馈不能直接等同于头摆sin/cos相位。当前场景始终前进，没有前行／倒退转换，不能借此声称复现其机制 |
| [Hawk et al., Neuron 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC5806692/) | AFD感觉阈值随近期温度适应，偏好行为还涉及突触前可塑性；感觉阈值适应与培养温度记忆可分离 | 不把去均值输入或一个适应时间常数同时解释为感觉适应与偏好记忆；当前固定偏好不是记忆形成模型 |
| [Tsukada et al., J. Neurosci. 2016](https://pubmed.ncbi.nlm.nih.gov/26936999/) | 自由运动动物的温度历史可通过识别的响应核重建AFD钙活动，报告约20秒的关键时间窗 | 4秒工程窗口没有覆盖该时间窗。钙响应核不等于单一膜时间常数，不能将所有节点时间常数直接改成20秒并称生物校准 |
| [Clark et al., J. Neurosci. 2006](https://pubmed.ncbi.nlm.nih.gov/16837592/) | AFD具有短期适应与振荡温度信号处理特征 | 有依据检验动态感觉编码；当前简单去均值或固定速率节点仍不是该神经元的功能复现 |

这些文献支持研究相应机制，不能单独证明经典8节点必须或足以完成当前工程追踪任务。经典子网也没有覆盖Ji研究涉及的完整运动反馈通路。

## 与现有实验如何衔接

当前[连接布局比较](reports/tracking-topology-2026-10-24.md)提示：感觉与行为接口、容量及优化充分程度都会影响成绩。因此先固定接口，交叉比较数据量和更新次数，并加入参数量接近的通用记忆网络。该比较完成前，不用更多细胞或时间常数搜索解释低分。

后续可检验的单因素包括：相同节点和参数预算下改变信号投影位置；在所有拓扑共享同一感觉前处理的条件下比较温度响应动态；在保留温度水平信息的同时改变历史长度。每项必须先明确观测权限、初态、可训练参数和实际测量对应关系。

如果研究前行持续性，再建立允许前行／倒退和短暂温度反向变化的任务，并把过去动作命令副本、实际运动状态与头摆相位分别处理。动作副本可以是工程干预，不能替代尚未证明的真实通路。当前不为引用该论文而直接添加RIM或强制反馈增益。

物理响应检查采用冻结控制器时，只能解释执行平滑、迟滞和抗噪行为。监督学习中若输入和标签完全不变，改变仿真执行器并不会改变离线拟合的损失函数；要讨论物理约束对训练的作用，需要明确它如何改变示范分布、策略访问轨迹或训练目标。
