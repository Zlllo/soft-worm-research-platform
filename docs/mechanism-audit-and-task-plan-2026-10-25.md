# 接口、功能机制审计与下一轮任务设计

执行状态更新（2026-10-25）：所述完整导航与选定功能机制的本轮检验已完成，现已阶段性结束。以下保留原始审计／方案语境；最新结果见[组员阶段总结](team-progress.md)与[几何控制复查](reports/navigation-feasible-2026-10-25.md)。细胞功能数据校准仍未完成。
日期：2026-10-25。区分已核查的实现事实、正在检验的功能假设与尚未实施的任务建议。

## 1. 节点之间的连接是否为当前任务所需

当前 full 接口把温度、温度历史均值和头摆相位输入所有节点，再从所有节点读出动作。代码存在不经过其他节点的输入—节点动态—读出路径；这不等于已经证明训练完成后不使用节点间连接。

新增两类检查：

- 冻结已训练真实图，分别关闭全部化学连接、gap连接、或全部节点间连接。最后一种保留化学自环与节点自身的泄漏响应。
- 重新训练只保留各节点自身动态、输入和读出的模型。统一32条静态示范、2048次更新及3个种子，先完成全部拟合再看行为。

在 restricted 接口下，隔离节点后的 RIA 读出不能依赖其他节点收到的温度和相位，单元测试已验证；在 full 接口下仍然能够依赖这些观测。该测试确认路径存在，不代替行为实验。

冻结后下降说明原控制器依赖该路径；隔离节点重训成功则说明任务存在无需节点间传递的解。重训失败只说明固定预算下未学会，不能证明任何优化器都学不会。保留 nominal 参数张量的屏蔽方法有无效参数，不能宣称这是与原网络有效容量匹配的竞争。

## 2. “真实连接模型”保留了哪些功能

| 项目 | 核查结果 | 对解释的影响 |
| --- | --- | --- |
| 解剖数据与边方向 | 已实现固定版本数据导入与检验；矩阵为源→目标 | 能研究指定解剖掩码；不能由解剖计数直接推断功能强度 |
| 化学连接强度与符号 | 随机初始化、自由学习；原始计数仅用于判断边是否存在 | 当前比较主要是连接布局，未复现有依据的功能符号或效能 |
| 节点动态 | 统一单状态速率模型、统一时间常数 | 尚未表达细胞类型差异、突触可塑性或亚细胞计算 |
| 感觉适应 | 4秒历史去均值并保留均值，且所有节点可读 | 工程前处理，不是已验证的AFD阈值适应模型 |
| 温度偏好 | 固定任务常数 | 未实现培养温度记忆及其形成过程 |
| 运动反馈 | 精确内部摆头相位，始终向前 | 未实现前行／倒退运动状态的持续性反馈 |
| RIA | 每侧单个标量节点 | 未实现分区钙动态及运动输入通路 |

复查的原始研究：

- [Hawk et al., Neuron 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC5806692/)区分AFD感觉适应与突触前可塑性／温度偏好记忆。它支持分别建模和检验这些过程，不能用一个统一时间常数替代两者。
- [Ji et al., eLife 2021](https://elifesciences.org/articles/68848)发现RIM依赖的运动反馈参与AIY的运动状态表示与前行持续性。当前8节点没有RIM，且没有倒退状态，所以不能声称已经检验该机制。
- [Hendricks et al., Nature 2012](https://www.nature.com/articles/nature11081)研究RIA分区钙活动与头部运动及感觉输入。该感觉运动整合证据不自动证明RIA对当前等温任务必需。

第二项审计的结论是“结构掩码部分已实现，关键功能机制仍待建模／校准”。这不等于现有代码实现错误，但目前还没有资格把掩码比较解释成完整生物回路优劣。后续应先选定机制，以原始刺激—响应记录或明确可检验的响应特征约束模型，再比较布局。

## 3. 若接口与功能机制合理，任务应怎样调整

### 优先任务：获得目标、维持追踪、受扰后重新获得

现有 TrackingConfig 的中心初始温差为舒适半宽的±0.4倍，全部处于舒适带内，方向是切向加±0.35弧度；教师训练设置虽增加到±0.8倍和±0.7弧度，初始中心温度仍在舒适带内。因此已有场景主要检验维持追踪，不是从未知朝向找到温区。

建议保留此任务为基础检查，另建明确的完整导航任务：

1. 从舒适带外的冷热两侧、均匀随机朝向开始；起始温差、位置和方向只用于生成与离线评价，不能输入策略。
2. 要求进入目标温带并保持一定时长的等温前进。
3. 预先安排一次场方向／等温线位置变化，检验重新定位和恢复。

当前配置明确禁止 initial_error_fraction≥1，不能仅把参数改大来实现；应单独扩展初态生成契约，并检查径向几何、教师或参考策略的可解性及动作上限。以上属于未实现建议。

主要指标分别报告首次进入时间、进入后追踪、扰动后恢复时间、失败比例；不能只报全程温带占比。通过学习曲线比较达到阈值所需的环境交互，避免只在最终成绩已接近100%时比较。

### 机制任务：针对明确的信息处理要求

| 假设机制 | 任务变化建议 | 必要对照 |
| --- | --- | --- |
| 感觉适应保留微小温度变化的可检测性 | 改变近期温度背景，目标偏好定义保持明确；先检验神经响应，再做导航 | 各拓扑交叉使用相同感觉前处理，区分适应收益与布局收益 |
| 感觉与自身运动信息的结合 | 控制环境变化族，比较主动采样与被动温变；改变运动速度或摆头节律 | 无／正确／错配运动反馈；先验证可辨识性，不能要求策略区分完全相同的观测 |
| 反馈维持行为状态 | 在允许前行／倒退的趋温任务中，区分短暂波动与持续变化 | 有／无相应反馈；先具备文献支持的路径与运动状态，不能直接套在现有8节点上 |

这些是可检验的机制假设，不是预测真实图一定领先。不能把所有机制与环境同时加入后，再把总分变化归因于解剖布局。

### 训练与确认方式

先检查简单参考控制器是否能解决新增任务、信息是否足够，再确认通用网络能学会。教师模仿可用于可学习性检查；主要闭环学习比较应给所有模型相同观测、动作、交互和调参预算，避免只比较拟合某个静态教师的效率。任务与未见参数范围在查看成绩前固定，不按真实图是否领先选择最终场景。

当前优先顺序：完成路径依赖实验 → 选定并核验细胞／反馈机制 → 实现获取—维持—重新获取任务 → 再做机制任务和学习效率比较。时间常数优化检查仍保留，但不替代“任务是否需要节点间连接”的核查。
