# 温度输入至身体输出：现有证据和模型假设

本表整理仓库已有文献阅读和模型记录，不是新文献系统综述。连接存在、细胞功能、效能标定及本项目仿真是不同证据；未知不视为没有连接。目标是给后续固定网络指定可审核接口，而非声明完整动物机制已重建。

| 环节 | 已有依据 | 本项目使用及限制 |
|---|---|---|
| 温度→AFD感觉神经元 | [Hawk等2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC5806692/)；仓库[闭环报告](reports/full302-closed-loop-2026-11-05.md)引用其温度适应时间尺度。 | 模型把温度经工程滤波和映射送入AFDL/AFDR；映射宽度、电流增益等并未拟合实测响应，不能把输入数值叫真实电流。 |
| AFD→AIY | 原始连接记录提供结构；Hawk等区分AFD感觉响应与传递调节。见[通路实验](reports/pathway-stage1-2026-11-03.md)。 | 当前模型关闭这组边会影响特定已训练策略，但不是活体因果复现；边的真实效能和完整作用方向未由电镜计数确定。 |
| AIY、AIZ、RIA等中间节点 | 仓库[导航诊断](reports/navigation-diagnosis-2026-11-02.md)沿途记录了响应，结构数据可检查具体连边。 | RIA是工程读出候选，不是已证明直接输出转向或温差；连接路径存在不保证有效传递。中间节点的统一动态是简化。 |
| 运动状态→中间回路 | [Ji等2021](https://elifesciences.org/articles/68848)研究RIM相关运动状态信号和AIY、持续运动；[文献记录](literature/neuromechanical-reading-2026-10-27.md)。 | 此证据不能单独确定一条直接RIM→AIY边的功能符号或效能；不能将工程相位输入直接等同实测运动反馈。 |
| 运动神经元→身体 | [Wen等2012](https://pmc.ncbi.nlm.nih.gov/articles/PMC3508473/)研究B类运动神经元参与弯曲传播；[c302框架](https://pmc.ncbi.nlm.nih.gov/articles/PMC6158223/)提供可选择细胞和动力学的模型。 | 实际神经-肌肉接头、肌肉响应与身体负载仍需独立校准；已有完整模型出现形变但没有可靠自主持续前进。固定网络本阶段不输出真实肌肉力或方向动作。 |

Cook连接数据的化学连接数量是电镜结构统计，不是功能权重或促进/抑制的测量；电连接按对称结构记录。详见 [连接数据说明](../data/connectome/README.md)。

## 接口下一步

固定一个公开可复现的温度刺激及校准目标，先验证AFD输入转换，再分别记录AFD、AIY、AIZ、RIA、运动相关节点；只读取RIA和全节点为两个工程对照，全节点包含输入节点、无法单独证明传递。以受控路径阻断和等规模非目标连接阻断比较，测沿途信号及输出，不将相关性直接当生物因果。动作接口应基于明确运动任务与神经-肌肉映射单独定义；在缺少定量标定前，不将工程读出描述为真实运动神经输出。
