## RFT 原型进入新核心前必须解决的问题

1. 波相位使用 `frequency * wave_speed`，局部形变速度只使用 `frequency`；相同相位演化会产生不同运动与耗散。
2. 改变波幅或弯曲偏置造成的点速度没有进入耗散；频率为零时仍可瞬间改变形状却记录零功。
3. 累计耗散与有限能量预算混在一起；能量归零后物理仍继续运动。
4. 材料坐标并未严格保持中心线弧长；中点采样与耗散积分使用了不同的 `ds`。
5. `com` 是运动参考点，但没有明确保证为几何或阻力中心；命名和力矩参考必须统一。
6. 边界整体回移和逐点裁剪不对应接触力；正式身体实验应使用大域截断或单独的壁面模型。
7. 固定阻力比 `1.4` 只能在说明介质与证据后采用，不能视为各种游动或爬行环境的通用常数。
8. 物理求解奇异时当前回退为零运动；新实现必须显式报告失败参数。

## 与并行工作的接口

第 1 阶段构建只依赖 `TemperatureField`、`LocalTemperatureSensor`、独立时钟和结果记录，不依赖旧 RFT、Streamlit 或强化学习。

身体整理可以同步开展，但第一项交付只是固定驱动的纯物理内核：输入连续、有限速率的形变参数，输出身体几何、刚体速度、力/力矩残差、瞬时耗散和累计耗散。通过物理与数值验证之后，才把第 1 阶段控制意图映射为转向驱动。

建议由原 PR 作者继续参与 RFT 重写，因为其工作日志保留了端点采样、镜像漂移、各向同性极限和训练速度尺度等探索经验。主分支评审以可重复的物理性质和数值收敛为准，不以旧测试数量或界面可运行为准。
